# 2교시 Codex 응용하기

> 연구소 과정은 직무에 맞는 데이터 트랙을 하나 선택합니다. CVD 공정 데이터는 아래 흐름으로 진행하고, R/F·CAE·S/W·전장 참석자를 위한 장비개발·제어 데이터 트랙은 **준비 중**입니다.

---

## 트랙 선택

- 공정·CVD 관련 직무 참석자는 **CVD 공정 데이터** 트랙을 선택합니다.
- R/F·CAE·S/W·전장 참석자는 **장비개발·제어 데이터** 트랙을 선택합니다. 이 트랙은 현재 **준비 중**이며, 실제 데이터 경로가 공개되기 전까지는 강사 안내를 따릅니다.

## 시작하기

CVD 공정 데이터 트랙은 1교시와 같은 `tes-lab` 폴더에서 대화창에 보냅니다.

```
@lab2
```

과정을 묻는 번호 선택지가 나오면 **1(연구소)** 를 보냅니다. 모든 STEP을 **같은 대화**에서 이어 합니다. 앞 STEP 결과를 다음 STEP이 이어 쓰기 때문입니다.

---

## 실습 자료

`2교시-연구소/` 폴더에 있는 교육용 가상 자료입니다. 실제 장비·고객사 자료가 아닙니다.

| 자료 | 내용 |
|---|---|
| `data/runs.csv` | 두 챔버(CH1·CH2)의 두 달치 생산 런 기록(세팅 파라미터 포함) |
| `data/measurements.csv` | 런마다 웨이퍼 49점의 두께 |
| `data/pm_log.csv` | 장비 점검(PM) 기록 |
| `data/doe.csv` | 세팅을 바꿔 가며 돌린 시험 런(DOE) |
| `tools/virtual-chamber.html` | 세팅값을 넣으면 두께를 예측하는 가상 장비 계산기 |

결과는 `2교시-연구소/outputs/`에 쌓입니다.

## STEP 순서

각 요청문을 보내기 전에 **지금 무엇을 하는지** 설명을 읽습니다. 파일 열기 → 자료 설명 → 분석 계획 → 숫자 표 → 그래프 → 검토 → 보고 순서로 진행합니다.

| 순서 | 지금 하는 일 | 복사할 요청문 | 예상 결과·확인할 것 |
|---|---|---|---|
| 1. 파일 열기 | 분석 전에 파일의 이름과 열을 확인합니다. | `2교시-연구소/data 폴더 안의 파일 이름과 각 파일의 열 이름을 읽고 초보자에게 설명해 줘. 파일은 바꾸지 마.` | 파일 목록과 열 설명이 나옵니다. 실제 폴더와 같은지 봅니다. |
| 2. 자료 설명 | 런·측정·점검·DOE 자료가 무엇을 뜻하는지 이해합니다. | `runs.csv, measurements.csv, pm_log.csv, doe.csv가 각각 무엇을 기록하는지, 기간·단위·주의할 점을 표로 설명해 줘. 모르는 것은 모른다고 표시해 줘.` | 자료 설명 표가 나옵니다. 날짜·단위·챔버 구분을 확인합니다. |
| 3. 분석 계획 | 가능한 관점을 보고 내가 고릅니다. | `실제 파일을 읽고 장비 상태를 볼 수 있는 분석 관점 5개를 제안해 줘. 각 관점의 질문·사용 파일·필요한 숫자를 적고 아직 계산하지 마.` → `2번과 4번을 선택할게. 분석 계획을 outputs/계획.md로 저장하고 확인할 가설도 적어 줘.` | 계획 파일이 생깁니다. 선택한 관점과 가설이 맞는지 봅니다. |
| 4. 숫자 표 | 그림보다 먼저 지표를 계산합니다. | `계획대로 런별 평균·균일도·중앙-가장자리 차를 숫자 표로 계산해 줘. 사용한 파일·계산식·단위를 적고 그래프는 아직 만들지 마.` | 런별 지표와 평소와 다른 구간 표가 나옵니다. 합계·단위·런 번호를 확인합니다. |
| 5. 그래프 | 확인한 숫자를 보기 쉽게 그립니다. | `방금 검토한 표를 바탕으로 분석을 한 화면의 HTML 대시보드로 만들어 줘. 그래프마다 챔버·기간·단위·출처 파일을 표시해 줘.` | 대시보드 HTML이 생깁니다. 숫자 표와 그래프가 같은지 봅니다. |
| 6. 검토 | 결과를 원자료와 다시 맞춥니다. | `대시보드 숫자 중 대조할 숫자 3개를 골라 원자료 어느 파일 몇 번째 줄에서 찾으면 되는지 알려 줘. 원인 후보와 반대 증거도 표로 정리하고 원인은 확정하지 마.` | 대조 목록과 원인 후보 표가 나옵니다. 파일을 직접 열어 숫자 하나 이상 확인합니다. |
| 7. 개선·보고 | 필요한 부분만 고치고 보고합니다. | `2번 그래프만 챔버 색을 구분해서 다시 그려 줘. 다른 표와 그래프는 그대로 둬.` → `오늘 분석을 한 장 보고로 정리해 줘: 현상 → 근거 숫자 → 원인 후보 → 추가로 확인할 것. 단위와 출처를 적어 줘.` | 고친 대시보드와 한 장 보고가 남습니다. 지정한 그래프만 바뀌었는지 확인합니다. |

### 선택 실습 — 내가 가져온 자료를 읽고 설명받기

시간이 남으면 개인정보와 사내 기밀을 제거한 공개 자료 또는 가상 파일을 교육 폴더에 추가해 볼 수 있습니다. 원본을 넣기 전에 교육 폴더 사용이 가능한지 강사에게 확인합니다.

```text
방금 추가한 파일을 먼저 읽고 파일 형식, 열 이름, 기간, 단위를 초보자에게 설명해 줘. 아직 분석하거나 파일을 고치지 마. 개인정보나 사내 기밀이 포함되어 있지 않은지 내가 확인할 항목도 알려 줘.
```

설명을 확인한 뒤에만 다음 요청을 보냅니다.

```text
이 자료로 할 수 있는 분석 관점 3개를 제안해 줘. 각 관점의 질문과 필요한 숫자만 적고, 내 선택 전에는 계산하거나 그래프를 만들지 마.
```

요청문은 그대로 복사해 보내도 됩니다. 다만 Codex가 만든 결과를 파일과 원자료에서 직접 확인합니다.

---

## 단계마다 지킬 것

- **결과부터 달라고 하지 않습니다.** "할 수 있어? 어떻게 해?" → 관점 펼치기 → 고르기 → 만들기 순서입니다.
- **관점은 내가 고릅니다.** Codex가 펼친 관점 번호가 화면마다 다를 수 있습니다. 내 화면의 번호로 고쳐 보냅니다.
- **그림보다 숫자 표가 먼저입니다.** 표에 날짜·런 번호·숫자 근거가 있는지 봅니다.
- **숫자 하나는 내 눈으로 맞춥니다.** Codex가 알려 준 줄을 메모장이나 엑셀로 직접 열어 확인합니다(머리글이 1번째 줄).
- **원인은 '후보'로 적습니다.** 근거 숫자와 반대 증거가 같이 있어야 합니다. "확정"이라고 쓰지 않았는지 봅니다.
- **계산기 예측은 참고용입니다.** 실제 장비 세팅은 담당자가 판단합니다.
- **고칠 때는 "다른 건 그대로".** 지정한 그림만 바뀌었는지 봅니다.

결과 문장은 사람마다 달라도 흐름과 남는 파일이 같으면 됩니다.
