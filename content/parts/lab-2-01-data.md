# 2교시 데이터 트랙 실습

> 연구소 과정은 직무에 맞는 데이터 트랙을 하나 선택합니다. CVD 공정 데이터는 아래 흐름으로 진행하고, R/F·CAE·S/W·전장 참석자를 위한 장비개발·제어 데이터 트랙은 **준비 중**입니다.

---

## 트랙 선택

- 공정·CVD 관련 직무 참석자는 **CVD 공정 데이터** 트랙을 선택합니다.
- R/F·CAE·S/W·전장 참석자는 **장비개발·제어 데이터** 트랙을 선택합니다. 이 트랙은 현재 **준비 중**이며, 실제 데이터 경로가 공개되기 전까지는 강사 안내를 따릅니다.

## 시작하기

CVD 공정 데이터 트랙은 1교시와 같은 `tes-lab` 폴더에서 대화창에 보냅니다.

```
2교시 시작
```

과정을 묻는 번호 선택지가 나오면 **1(연구소)** 를 보냅니다. 모든 STEP을 **같은 대화**에서 이어 합니다. 앞 STEP 결과를 다음 STEP이 이어 쓰기 때문입니다.

---

## 실습 자료

`2교시-연구소/` 폴더에 있는 교육용 가상 자료입니다. 실제 장비·고객사 자료가 아닙니다.

| 자료 | 내용 |
|---|---|
| `data/runs.csv` | 두 챔버(CH1·CH2)의 두 달치 생산 런 기록(세팅 파라미터 포함) |
| `data/measurements.csv` | 런마다 웨이퍼 49점의 두께 |
| `data/pm_log.csv` | 장비 점검(PM) 기록 |
| `data/doe.csv` | 세팅을 바꿔 가며 돌린 시험 런(DOE) |
| `tools/virtual-chamber.html` | 세팅값을 넣으면 두께를 예측하는 가상 장비 계산기 |

결과는 `2교시-연구소/outputs/`에 쌓입니다.

---

## STEP 순서

| STEP | 단계 | 보내는 요청문 | 남는 것 |
|---|---|---|---|
| 1 | 업무 파악 | `2교시-연구소/data 폴더에 장비 런 기록이랑 측정 데이터가 있는데, 이걸로 장비 상태가 괜찮은지 보고 싶어. 할 수 있어? 어떻게 해?` | 자료 요약과 분석 방법 |
| 2 | 기획 | `실제로 데이터를 훑어보고 어떤 관점으로 볼 수 있는지 5개 펼쳐 줘. …` → 두 개를 골라 `… 분석 계획을 계획.md로 저장해 줘. 확인할 가설도 적어 줘` | `outputs/계획.md` |
| 3 | 만들기 — 분석 | `계획대로 먼저 숫자로 분석해 줘. 런별 평균·균일도·중앙-가장자리 차를 계산하고, …` | 런별 지표 표, 평소와 다른 구간 표 |
| 4 | 만들기 — 시각화 | `이 분석을 한 화면에서 보는 HTML 대시보드로 만들어 줘. …` | 대시보드 HTML |
| 5 | 검토 | `대시보드 숫자 중 대조용 3개를 골라 원자료 어느 파일 몇 번째 줄에서 찾으면 되는지 알려 줘` → 직접 대조 → 원인 후보 표 | 대조 결과, 원인 후보 표 |
| 6 | 개선 — 조정 | `DOE 결과로 간격·압력과 균일도 관계를 간단히 모델로 만들고, …` → 제안값을 계산기에 넣어 보기 | 세팅 조정안 |
| 7 | 개선 — 고치기·보고 | `2번 그림만 챔버 색을 구분해서 다시 그려 줘. 다른 건 그대로` → `오늘 분석을 한 장 보고로 정리해 줘: …` | 고친 대시보드, 한 장 보고 |

요청문 전체는 Codex 화면에 복사용으로 나옵니다. 그대로 복사해 보내면 됩니다.

---

## 단계마다 지킬 것

- **결과부터 달라고 하지 않습니다.** "할 수 있어? 어떻게 해?" → 관점 펼치기 → 고르기 → 만들기 순서입니다.
- **관점은 내가 고릅니다.** Codex가 펼친 관점 번호가 화면마다 다를 수 있습니다. 내 화면의 번호로 고쳐 보냅니다.
- **그림보다 숫자 표가 먼저입니다.** 표에 날짜·런 번호·숫자 근거가 있는지 봅니다.
- **숫자 하나는 내 눈으로 맞춥니다.** Codex가 알려 준 줄을 메모장이나 엑셀로 직접 열어 확인합니다(머리글이 1번째 줄).
- **원인은 '후보'로 적습니다.** 근거 숫자와 반대 증거가 같이 있어야 합니다. "확정"이라고 쓰지 않았는지 봅니다.
- **계산기 예측은 참고용입니다.** 실제 장비 세팅은 담당자가 판단합니다.
- **고칠 때는 "다른 건 그대로".** 지정한 그림만 바뀌었는지 봅니다.

결과 문장은 사람마다 달라도 흐름과 남는 파일이 같으면 됩니다.

## 막히거나 늦을 때

| 상황 | 이렇게 보냅니다 |
|---|---|
| 막혔다 | `도와줘` |
| 시간이 모자란다 | `건너뛰기` — 그 STEP의 모범 결과를 받아 다음 STEP으로 갑니다 |
| 어디까지 했는지 모르겠다 | `어디까지 했지` |
| 묻지 않은 계산·그림까지 만들었다 | `요청한 것만 해 줘` |

빨리 끝났으면 Codex가 마지막에 안내하는 "더 해 보기" 요청문을 해 봅니다.
