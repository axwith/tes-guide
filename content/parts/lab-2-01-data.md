# 2교시 Codex 응용하기

> 가상 증착 장비(CVD)의 런 기록과 웨이퍼 두께 데이터로 1교시와 같은 5단계(업무 파악·기획·만들기·검토·개선)를 진행합니다.

---

## 휴식 시간에 할 일

1교시가 끝난 휴식 시간에 아래 두 가지를 해 둡니다. 휴식 시간에 못 했으면 2교시를 시작할 때 합니다.

### ① 2교시 실습 폴더 받기

**[2교시 실습 폴더 받기 (2교시-Codex-응용하기.zip)](/downloads/2교시-Codex-응용하기.zip)**

1. 위 링크로 ZIP 파일을 받습니다.
2. 압축을 풉니다.
   - Windows: 받은 파일을 오른쪽 클릭 → **모두 압축 풀기** → **찾아보기**를 눌러 **바탕 화면**을 고르고 → **압축 풀기**
   - Mac: 받은 파일을 더블클릭하고, 생긴 폴더를 바탕 화면으로 옮깁니다.
3. `2교시-Codex-응용하기` 폴더 안에 `data`, `tools`, `outputs` 폴더와 `README.md`가 보이면 됩니다. 열었는데 `2교시-Codex-응용하기` 폴더가 한 번 더 보이면, 그 안쪽 폴더를 씁니다.

### ② 3교시 업무 공간 설치

3교시에 쓸 내 업무 공간을 설치합니다.

**Windows** — 시작 버튼을 누르고 `PowerShell`을 입력해 **Windows PowerShell**을 엽니다. 파란(또는 검은) 창에 아래 한 줄을 붙여 넣고 Enter를 누릅니다.

```powershell
irm https://raw.githubusercontent.com/axwith/tes-workmate/main/get.ps1 | iex
```

**Mac** — Spotlight(⌘+스페이스)에서 `터미널`을 찾아 열고, 아래 한 줄을 붙여 넣고 Enter를 누릅니다.

```bash
curl -fsSL https://raw.githubusercontent.com/axwith/tes-workmate/main/install.sh | bash
```

1. 설치 중 `주 업무 폴더 경로`를 묻습니다. 모르면 그냥 Enter를 누릅니다(최근 업무 파일을 알아서 찾습니다). 업무 파일을 모아 둔 폴더가 있으면 그 경로를 넣습니다.
2. 마지막에 `발견 파일 수`, `본문 추출 수`, `설치 완료`가 나오면 됩니다.
3. 이어서 설치된 폴더가 파일 탐색기(Mac은 Finder)로 열립니다. 확인만 하고 닫아도 됩니다. Codex에서 여는 것은 3교시에 합니다.

설치 위치는 Windows `문서\3교시-Codex-활용하기`(OneDrive를 쓰는 PC는 `OneDrive\문서\3교시-Codex-활용하기`), Mac `~/Documents/3교시-Codex-활용하기`입니다.

이미 `tes-workmate`라는 이름으로 설치한 적이 있어도 같은 명령을 실행합니다. 새 폴더 `3교시-Codex-활용하기`가 따로 생기고, 3교시에는 새 폴더를 씁니다.

## 시작하기

1. Codex 앱 왼쪽 위에서 **새 채팅**을 누릅니다.
2. 입력창 바로 위 **프로젝트 선택**을 누르고, 목록 맨 아래의 **새 프로젝트**를 누릅니다.

   ![입력창 위 프로젝트 선택 목록과 맨 아래의 새 프로젝트](/images/win/09.jpg)

3. "프로젝트 만들기" 창에서 소스 폴더 칸 가운데 **추가**를 누릅니다.

   ![프로젝트 만들기 창의 소스 폴더 추가 버튼](/images/win/10.jpg)

4. 폴더 고르는 창 왼쪽에서 **바탕 화면**을 누르고, 압축을 푼 `2교시-Codex-응용하기` 폴더를 한 번 눌러 고른 뒤 **폴더 선택**을 누릅니다. 폴더 안으로 들어가지 말고 고른 상태에서 누릅니다.
5. 맨 위 프로젝트 이름 칸에 `2교시-Codex-응용하기`을 적고 오른쪽 아래 **프로젝트 만들기**를 누릅니다.
6. "이 폴더를 신뢰할까요?" 창이 뜨면 경로 끝이 `2교시-Codex-응용하기`인지 보고 **폴더 신뢰**를 누릅니다.
7. 입력창 바로 위에 `2교시-Codex-응용하기`가 보이면 연결된 것입니다. 대화창에 아래 한 줄을 보냅니다.

```text
@lab2
```

Codex가 2교시 전체 보기와 자료 확인 결과(`준비 완료: data 파일 4개…`)를 보여 주고, 바로 STEP 1 설명과 첫 요청문을 이어서 보여 줍니다.

### 진행 방법

- Codex 답의 맨 아래에는 늘 **지금 보낼 말** 상자가 하나 있습니다. 그 문장을 그대로 복사해 보냅니다.
- Codex가 실행한 뒤 **확인할 것**과 다음 **지금 보낼 말**을 보여 줍니다. 확인하고 다음 문장을 보냅니다.
- STEP 하나가 끝나면 Codex가 결과 확인과 다음 STEP 설명·첫 요청문을 한 번에 보여 줍니다. `다음`을 따로 보낼 필요가 없습니다.
- 모든 STEP을 **같은 대화**에서 이어 합니다. 앞 STEP 결과를 다음 STEP이 이어 쓰기 때문입니다.

## STEP 순서

| STEP | 지금 하는 일 | 복사할 요청문 | 확인할 것 |
|---|---|---|---|
| 1. ① 업무 파악 | 결과부터 달라고 하지 않고 할 수 있는지부터 묻습니다 | `data 폴더에 장비 런 기록이랑 측정 데이터가 있는데, 이걸로 장비 상태가 괜찮은지 보고 싶어. 할 수 있어? 어떻게 해?` | 런 수(243런)·기간(2026-09-01~10-31)·챔버(CH1·CH2)가 나오는지, 계산·그림 파일을 아직 만들지 않았는지 |
| 2. ② 기획 | 관점 5개를 펼쳐 받고 두 개를 고릅니다 | `실제로 데이터를 훑어보고 어떤 관점으로 볼 수 있는지 5개 펼쳐 줘. 관점마다 볼 지표와 어울리는 그림도 같이` → `관점 1 런별 균일도 추이랑 관점 2 챔버 비교로 갈게. 분석 계획을 계획.md로 저장해 줘. 확인할 가설도 적어 줘` | `outputs/계획.md`에 지표 정의·기준선·만들 그림·가설이 있는지. 관점 번호가 내 화면과 다르면 내 화면의 번호로 고쳐 보냅니다 |
| 3. ③ 만들기(숫자 표) | 그림 전에 숫자 표부터 만듭니다 | `계획대로 먼저 숫자로 분석해 줘. 런별 평균·균일도·중앙-가장자리 차를 계산하고, 평소와 다른 구간을 날짜와 런 번호로 표로 정리해 줘` | 표에 날짜·런 번호·숫자 근거(9월 기준 대비 얼마)가 있는지 |
| 4. ③ 만들기(대시보드) | 분석을 한 화면 대시보드로 만듭니다 | `이 분석을 한 화면에서 보는 HTML 대시보드로 만들어 줘. 런별 추이에 PM·레시피 변경 날짜를 세로선으로, 이상 구간은 색으로. 정상 런과 이상 런 웨이퍼 분포 그림도 하나씩` | 대시보드를 브라우저로 열어 그림이 다 보이는지, 세로선 위치가 `data/pm_log.csv` 날짜와 맞는지 |
| 5. ④ 검토 | 숫자 하나는 내 눈으로 맞추고, 원인은 '후보'로 정리합니다 | `대시보드 숫자 중 대조용 3개를 골라 원자료 어느 파일 몇 번째 줄에서 찾으면 되는지 알려 줘` → (숫자 하나를 직접 대조한 뒤) `이상 구간 3곳마다 원인 후보를 근거 숫자와 반대 증거로 표에 정리해 줘` | 알려 준 줄을 메모장·엑셀로 직접 열어 맞춰 봤는지(머리글이 1번째 줄). 후보마다 근거 숫자와 반대 증거가 있고 "확정"이라고 쓰지 않았는지 |
| 6. ⑤ 개선(조정) | 세팅 조합을 받아 가상 장비 계산기에 넣어 봅니다 | `DOE 결과로 간격·압력과 균일도 관계를 간단히 모델로 만들고, CH1 균일도를 기준 이하로 되돌릴 조합을 2개 제안해 줘` | 제안값을 `tools/virtual-chamber.html`(더블클릭 → 챔버 CH1 → spacing·pressure 입력)에 넣어 "목표 이내"가 나오는지 |
| 7. ⑤ 개선(고치기·보고) | 그림 하나만 고치고, 오늘 분석을 한 장 보고로 정리합니다 | `2번 그림만 챔버 색을 구분해서 다시 그려 줘. 다른 건 그대로` → `오늘 분석을 한 장 보고로 정리해 줘: 현상 → 근거 → 원인 후보 → 조정안 → 확인할 것` | 다른 그림이 그대로인지, 한 장 보고에 조정안과 "실제 조정은 담당자 판단"이 있는지 |

화살표(→)로 이어진 요청문은 하나씩 따로 보냅니다. Codex 화면에는 지금 보낼 요청문 하나만 나오니, 화면의 지금 보낼 말을 그대로 보내면 됩니다.

### 정리

STEP 7이 끝나면 Codex가 정리 요청문을 지금 보낼 말로 보여 줍니다.

```text
outputs 에 오늘 남은 파일을 5단계(업무 파악·기획·만들기·검토·개선)별로 표로 보여 줘. 파일마다 여는 법도 같이
```

**확인할 것:** 계획.md, 분석 표, 대시보드, 검토, 조정안, 한 장 보고가 다 있는지 봅니다.

## 단계마다 지킬 것

- **결과부터 달라고 하지 않습니다.** "할 수 있어? 어떻게 해?" → 관점 펼치기 → 고르기 → 만들기 순서입니다.
- **관점은 내가 고릅니다.** Codex가 펼친 관점 번호가 화면마다 다를 수 있습니다.
- **그림보다 숫자 표가 먼저입니다.** 표가 맞아야 그림도 맞습니다.
- **숫자 하나는 내 눈으로 맞춥니다.**
- **원인은 '후보'로 적습니다.** 근거 숫자와 반대 증거가 같이 있어야 합니다.
- **계산기 예측은 참고용입니다.** 실제 장비 세팅은 담당자가 판단합니다.
- **고칠 때는 "다른 건 그대로".** 지정한 그림만 바뀌었는지 봅니다.
