# 미리 해 볼 것

> 설치와 첫 요청을 마쳤다면, 교육 전에 아래 요청을 한두 개 해 보세요. 하지 않아도 교육은 따라올 수 있습니다.
> 먼저 데모 파일로 만든 연습 폴더를 정리해 보고, 손에 익으면 내가 정리하고 싶은 폴더로 같은 순서를 해 봅니다.

설치와 첫 요청을 마쳤다면 교육 전에 아래 요청을 한두 개 해 보세요. 하지 않아도 교육은 따라올 수 있습니다. 먼저 데모 파일로 만든 연습 폴더를 정리해 보고, 손에 익으면 내가 정리하고 싶은 폴더로 같은 순서를 해 봅니다.

모두 [작업 폴더 연결과 첫 요청](#part-1-03-first-request)에서 만든 **codex-교육** 프로젝트에서 합니다. 왼쪽 위가 **Codex** 인지, 입력창 오른쪽 아래 모델이 **GPT-6.1 Terra** 인지 확인하고, 왼쪽 목록에서 **codex-교육** 을 누르면 새 대화로 시작해 이전 대화와 섞이지 않습니다.

---

## 1. 연습 폴더를 만듭니다

정리해 볼 폴더가 먼저 필요합니다. 아래 문장을 그대로 보내면 Codex가 codex-교육 안에 데모 파일 20개가 든 `정리-연습` 폴더를 만듭니다.

```text
정리-연습 폴더를 만들고, 그 안에 정리 연습용 데모 파일 20개를 만들어 줘. 보고서·견적서·회의록·사진·압축 파일처럼 다운로드 폴더에 흔히 쌓이는 이름으로, pdf·docx·xlsx·csv·pptx·jpg·png·zip·txt를 골고루 섞어 줘. 내용은 비어 있어도 돼
```

![정리-연습 폴더와 빈 파일 20개를 만들었다는 답](/images/practice/01.jpg)

탐색기(Mac은 Finder)에서 바탕 화면 → codex-교육 → 정리-연습을 열어 보면 파일이 한 폴더에 섞여 있습니다. 파일 이름은 사람마다 조금씩 다르게 만들어집니다.

![정리-연습 폴더 안에 섞여 있는 데모 파일 20개](/images/practice/02.jpg)

---

## 2. 정리 계획만 먼저 받습니다

바로 옮기라고 하지 말고, 계획부터 받습니다. 파일을 움직이기 전에 어떻게 나눌지 내 눈으로 확인하는 습관이 제일 중요합니다.

```text
정리-연습 폴더를 정리하려는데 어떻게 하면 좋을까? 먼저 어떤 파일이 있는지 보고 정리 계획만 알려 줘. 아직 파일은 옮기지 마
```

![파일 종류별 개수와 폴더별 정리 계획을 알려 준 답](/images/practice/03.jpg)

계획이 마음에 들지 않으면 "보고서는 따로 모아 줘", "날짜별로 나눠 줘"처럼 말로 고쳐 달라고 하면 됩니다.

---

## 3. 계획대로 정리하라고 합니다

계획이 괜찮으면 정리를 맡깁니다. 지우는 파일이 없게 해 달라고 꼭 덧붙여 주세요.

```text
좋아. 그 계획대로 정리해 줘. 지우는 파일은 하나도 없게 해 줘
```

![계획을 확인한 뒤 정리해 달라고 입력한 화면](/images/practice/04.jpg)

20~30초 뒤 폴더별 파일 수와 함께 정리가 끝났다는 답이 옵니다. 중간에 허락을 묻는 창이 뜨면 무엇을 하려는지 읽어 보고 눌러 주세요.

![폴더별 파일 수와 삭제한 파일이 없다는 답](/images/practice/05.jpg)

---

## 4. 빠진 파일이 없는지 세어 보게 합니다

정리가 끝나면 결과를 다시 확인하게 합니다. Codex의 "끝났습니다"를 그대로 믿지 말고 숫자로 확인받는 연습입니다.

```text
정리 결과 보여 줘. 빠진 파일 없이 처음 20개가 다 있는지 세어 줘
```

![폴더별 파일 수 표와 빠진 파일 0개라는 검증 결과](/images/practice/06.jpg)

탐색기에서 정리-연습 폴더를 다시 열면 종류별 폴더가 생겨 있습니다.

![정리-연습 폴더 안에 종류별로 만들어진 폴더](/images/practice/07.jpg)

연습 폴더는 지워도 되고, 다시 해 보고 싶으면 1번부터 다시 하면 됩니다.

---

## 5. 내가 정리하고 싶은 폴더로 해 봅니다

연습 폴더에서 순서가 손에 익었다면, 평소 정리가 안 되는 내 폴더(예: 다운로드 폴더)로 같은 순서를 해 봅니다.

1. [작업 폴더 연결과 첫 요청](#part-1-03-first-request) 1~2단계로 새 프로젝트 창을 열고, 소스 폴더로 정리하고 싶은 폴더를 골라 4~6단계처럼 프로젝트를 만듭니다(3단계 새 폴더 만들기는 건너뜁니다).
2. 처음에는 계획만 받습니다.

```text
이 폴더를 정리하고 싶어. 파일이 몇 개고 어떤 종류가 있는지 보고, 어떻게 정리하면 좋을지 계획만 알려 줘. 파일은 하나도 옮기거나 지우지 마
```

3. 계획을 읽고 괜찮을 때만 위 2~4절처럼 "그 계획대로 정리해 줘. 지우는 파일은 하나도 없게 해 줘"와 "빠진 파일 없이 다 있는지 세어 줘"를 차례로 보냅니다.

> 회사 기준상 승인되지 않은 사내 자료가 든 폴더, 공유 드라이브, 업무용 중요 폴더는 열지 마세요. 개인 다운로드 폴더처럼 정리 순서가 바뀌어도 괜찮은 폴더로 해 보세요.

## 더 해 볼 만한 요청

시간이 남으면 codex-교육 프로젝트에서 아래 요청도 하나씩 보내 보세요. 모두 codex-교육 폴더 안에 파일을 만듭니다.

**메모 파일 만들기**

```text
오늘 교육 메모.md 파일을 만들고 첫 줄에 오늘 날짜와 "Codex 첫 실습"이라고 적어 줘
```

**웹페이지 한 장 만들기**

```text
오늘 날짜 기준으로 재밌는 운세를 만들어 줘. 전체운·금전운·연애운을 넣어서 예쁜 HTML 카드로 만들고 이 폴더에 저장해 줘
```

만들어진 HTML 파일을 두 번 누르면 브라우저에서 열립니다. 색이나 문구를 바꾸고 싶으면 "배경을 보라색으로 바꿔 줘"처럼 이어서 말하면 됩니다.

**표 데이터 집계하기**

```text
가상의 불량 기록 50건을 불량기록.csv로 만들어 줘. 날짜, 공정, 불량 유형 열을 넣어 줘. 그다음 불량 유형별 건수를 세서 불량요약.md로 정리하고, 건수 합이 50인지도 확인해 줘
```
