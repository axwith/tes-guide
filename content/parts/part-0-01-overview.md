## 당일 하는 일

하루는 50분씩 세 교시입니다. 교시 사이에 쉬는 시간이 있습니다.

| 교시 | 하는 일 |
|---|---|
| 1교시 **Codex 시작하기** | 실습 폴더를 받아 새 채팅에서 프로젝트로 엽니다. Codex의 기본 흐름을 익히고, 폴더 둘러보기 → 다운로드 폴더 정리 → 플러그인 설치 → 오늘 이슈 설명 자료 만들기 순서로 진행합니다. |
| 2교시 **Codex 응용하기** | 연구소 과정은 CVD 공정 데이터를 분석해 대시보드와 한 장 보고를 만들고, 혼합직무 과정은 무신사·크림·네이버 증권 가운데 하나에서 웹 자료를 모아 분석 자료 한 장을 만듭니다. |
| 3교시 **Codex 활용하기** | 내 업무 공간 `tes-workmate`를 열어 내 업무를 알려 줍니다. 연구소 과정은 2교시 분석을 내 스킬로 만든 뒤 내 업무 한 건을 해 보고, 혼합직무 과정은 예시 자료로 업무 결과물을 만들어 고쳐 봅니다. |

3교시에 꾸린 내 업무 공간은 교육이 끝난 뒤에도 그대로 쓸 수 있습니다.

교시별 세부 안내와 실습 폴더는 과정 페이지에 있습니다. 실제 사내 자료는 가져오지 않으셔도 됩니다.

## 준비물

- 노트북(Windows 또는 Mac)과 충전기
- 회사 ChatGPT 계정(Codex를 쓸 수 있는 계정)
- 교육 전에 설치를 마친 ChatGPT 데스크톱 앱
- 3교시에 다뤄 볼 내 업무 하나(생각만 해 오시면 됩니다)

| 노트북 | 사양 |
|---|---|
| Windows | Windows 11 권장, Windows 10은 1809 이상 |
| Mac | macOS 14 이상의 Apple Silicon(M1 이상) |

Intel 칩 Mac은 앱을 설치하지 말고 교육 담당자에게 미리 알려 주세요.

---

## 전체 준비 순서

Codex는 새 ChatGPT 데스크톱 앱에 들어 있습니다. 앱 왼쪽 위 **ChatGPT** 를 눌러 **Codex** 로 바꿔서 씁니다. 예전 앱 "ChatGPT Classic"에는 Codex가 없습니다.

막히는 곳이 없으면 준비에는 30분 정도 걸립니다.

| 단계 | 할 일 | 끝나면 |
|---|---|---|
| 1 | 노트북 사양 확인 | 위 사양표에 맞는지 확인됨 |
| 2 | ChatGPT 데스크톱 앱 설치 | [Windows](#part-1-01-windows) 또는 [Mac](#part-1-02-mac) 안내를 마침 |
| 3 | 회사 계정으로 로그인 | 회사 워크스페이스가 선택돼 있음 |
| 4 | 왼쪽 위 ChatGPT를 눌러 Codex로 바꾸기 | 왼쪽 위에 Codex가 보임 |
| 5 | 바탕 화면에 `codex-교육` 폴더를 만들어 프로젝트로 연결 | 프로젝트 목록에 `codex-교육`이 보임 |
| 6 | 모델을 GPT-6.1 Terra로 바꾸고 [첫 요청 보내기](#part-1-03-first-request) | 답이 오고 `hello.txt` 파일이 만들어짐 |
| 7 | (선택) [미리 해 볼 것](#part-1-04-practice) | 연습 폴더를 계획 → 정리 → 확인 순서로 정리해 봄 |
| 8 | [교육 전 점검표](#part-2-01-checklist) 확인 | 모든 항목에 체크 |

## 왜 교육 전에 마쳐야 하나요

교육 당일에는 설치 시간을 따로 두지 않고 바로 실습을 시작합니다.

설치하거나 처음 실행할 때 관리자 승인 창이 뜰 수 있습니다. 승인은 IT 담당 부서를 거쳐야 해서 시간이 걸리고, 교육 당일에는 받기 어렵습니다.

## 교육 중 지킬 것

- Codex는 내가 연 폴더 안의 파일을 읽고 고칠 수 있습니다. 교육 중에는 교육용 폴더만 열어 주세요.
- 회사 기준상 승인되지 않은 사내 자료는 앱에 넣지 마세요.
- API 키는 쓰지 않습니다. 앱에서 API 키 입력을 묻더라도 넣지 마세요.
- 숫자나 결론이 나오면 원자료와 직접 대조해 확인합니다.
