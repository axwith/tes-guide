# 교육 안내

> 테스 Codex 실습 교육은 처음부터 끝까지 각자 노트북으로 직접 실습합니다.
> 당일 바로 시작할 수 있도록 **11월 20일(금)까지** 아래 준비를 마쳐 주세요.

---

## 일정

| 항목 | 내용 |
|---|---|
| 교육 일정 | 2026년 11월 24일(화)~26일(목) |
| 시간 | 매일 13:30~16:30 |
| 강사 | AXwith 이철로 |
| 사전 준비 기한 | 11월 20일(금) |

---

## 두 과정

교육은 두 과정으로 나뉩니다.

| 과정 | 회차 |
|---|---|
| 연구소 과정 | 1·2회차(같은 내용) |
| 혼합직무 과정 | 3회차 |

과정별 교시 안내는 준비되는 대로 이 페이지에 올립니다. 설치와 점검표는 두 과정이 같습니다.

---

## 준비물

- 노트북(Windows 또는 Mac)과 충전기
- 회사 ChatGPT 계정(Codex를 쓸 수 있는 계정)
- 교육 전에 설치를 마친 ChatGPT 데스크톱 앱

| 노트북 | 사양 |
|---|---|
| Windows | Windows 11 권장, Windows 10은 1809 이상 |
| Mac | macOS 14 이상의 Apple Silicon(M1 이상) |

Intel 칩 Mac은 앱을 설치하지 말고 교육 담당자에게 미리 알려 주세요.

---

## 왜 11월 20일까지인가요

설치하거나 처음 실행할 때 관리자 승인 창이 뜰 수 있습니다. 관리자 승인은 IT 담당 부서를 거쳐야 해서 시간이 걸리고, 교육 당일에는 해결하기 어렵습니다. 미리 설치하고 첫 요청까지 보내 두면 당일에는 바로 실습을 시작할 수 있습니다.

---

## 앱에 대해 먼저 알아 둘 것

Codex는 **새 ChatGPT 데스크톱 앱** 안에 들어 있습니다. 따로 Codex 앱을 찾지 않으셔도 됩니다.

- 앱 위쪽의 Chat/Work 가운데 **Work** 화면에서 프로젝트(폴더)를 연결해 작업합니다.
- 예전 앱은 이름이 "ChatGPT Classic"으로 바뀌었고, Classic에는 Codex가 없습니다.

---

## 전체 준비 순서

| 단계 | 할 일 | 끝나면 |
|---|---|---|
| 1 | 노트북 사양 확인 | 위 사양표에 맞는지 확인됨 |
| 2 | ChatGPT 데스크톱 앱 설치 | [Windows](#part-1-01-windows) 1~7단계 또는 [Mac](#part-1-02-mac) 안내를 마침 |
| 3 | 회사 계정으로 로그인 | 회사 워크스페이스가 선택돼 있음 |
| 4 | 바탕 화면의 `codex-교육` 폴더를 프로젝트로 연결 | 프로젝트 목록에 `codex-교육`이 보임 |
| 5 | 첫 요청 보내기 | 답이 오고 `hello.txt` 파일이 만들어짐 |
| 6 | (선택) [미리 해 볼 것](#part-1-04-practice) | 연습 폴더를 계획 → 정리 → 확인 순서로 정리해 봄 |
| 7 | [교육 전 점검표](#part-2-01-checklist) 확인 | 모든 항목에 체크 |

설치를 끝내지 못하셨어도 괜찮습니다. 11월 20일(금)까지 막힌 단계를 교육 담당자에게 알려 주시면 교육 전에 함께 확인하겠습니다.

---

## 교육 중 지킬 것

- Codex는 내가 연 폴더 안의 파일을 읽고 고칠 수 있습니다. 교육 중에는 교육용 폴더만 열어 주세요.
- 회사 기준상 승인되지 않은 사내 자료는 앱에 넣지 마세요.
- API 키는 쓰지 않습니다. 앱에서 API 키 입력을 묻더라도 넣지 마세요.
