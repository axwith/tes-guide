> 당일 바로 시작할 수 있도록 **11월 20일(금)까지** 아래 준비를 마쳐 주세요.

## 당일 하는 일

하루는 1교시와 2교시로 나뉩니다.

| 교시 | 하는 일 |
|---|---|
| 1교시 | 준비된 실습 폴더에서 Codex에 요청하고, 결과를 확인하고, 고쳐 달라고 다시 요청하며 결과물을 만듭니다. |
| 2교시 | 1교시 폴더가 어떻게 짜여 있는지 살펴보고, 내 업무에 맞는 폴더를 새로 꾸려 직접 실행해 봅니다. |

2교시에 꾸린 폴더는 교육이 끝난 뒤에도 그대로 쓸 수 있습니다.

과정별 세부 안내와 실습 자료 받는 방법은 **11월 20일(금)에 이 페이지에 올립니다.** 실제 사내 자료는 가져오지 않으셔도 됩니다.

## 준비물

- 노트북(Windows 또는 Mac)과 충전기
- 회사 ChatGPT 계정(Codex를 쓸 수 있는 계정)
- 교육 전에 설치를 마친 ChatGPT 데스크톱 앱
- 2교시에 다뤄 볼 내 업무 하나(생각만 해 오시면 됩니다)

| 노트북 | 사양 |
|---|---|
| Windows | Windows 11 권장, Windows 10은 1809 이상 |
| Mac | macOS 14 이상의 Apple Silicon(M1 이상) |

Intel 칩 Mac은 앱을 설치하지 말고 교육 담당자에게 미리 알려 주세요.

---

## 전체 준비 순서

Codex는 새 ChatGPT 데스크톱 앱의 **Work** 화면에서 씁니다. 예전 앱 "ChatGPT Classic"에는 Codex가 없습니다.

막히는 곳이 없으면 준비에는 30분 정도 걸립니다.

| 단계 | 할 일 | 끝나면 |
|---|---|---|
| 1 | 노트북 사양 확인 | 위 사양표에 맞는지 확인됨 |
| 2 | ChatGPT 데스크톱 앱 설치 | [Windows](#part-1-01-windows) 또는 [Mac](#part-1-02-mac) 안내를 마침 |
| 3 | 회사 계정으로 로그인 | 회사 워크스페이스가 선택돼 있음 |
| 4 | 바탕 화면에 `codex-교육` 폴더를 만들어 프로젝트로 연결 | 프로젝트 목록에 `codex-교육`이 보임 |
| 5 | [첫 요청 보내기](#part-1-03-first-request) | 답이 오고 `hello.txt` 파일이 만들어짐 |
| 6 | (선택) [미리 해 볼 것](#part-1-04-practice) | 연습 폴더를 계획 → 정리 → 확인 순서로 정리해 봄 |
| 7 | [교육 전 점검표](#part-2-01-checklist) 확인 | 모든 항목에 체크 |

## 왜 11월 20일까지인가요

교육 당일에는 설치 시간을 따로 두지 않고 바로 실습을 시작합니다.

설치하거나 처음 실행할 때 관리자 승인 창이 뜰 수 있습니다. 승인은 IT 담당 부서를 거쳐야 해서 시간이 걸리고, 교육 당일에는 받기 어렵습니다.

## 교육 중 지킬 것

- Codex는 내가 연 폴더 안의 파일을 읽고 고칠 수 있습니다. 교육 중에는 교육용 폴더만 열어 주세요.
- 회사 기준상 승인되지 않은 사내 자료는 앱에 넣지 마세요.
- API 키는 쓰지 않습니다. 앱에서 API 키 입력을 묻더라도 넣지 마세요.
- 숫자나 결론이 나오면 원자료와 직접 대조해 확인합니다.
