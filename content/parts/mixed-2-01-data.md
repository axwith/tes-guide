## 다섯 단계

### ① 방법 찾기 (업무 파악)

그 사이트에서 어떤 정보를 가져올 수 있는지 먼저 살펴봅니다. 아직 저장하지 않습니다.

```text
insane-search로 {대상}에서 어떤 정보를 가져올 수 있는지 살펴봐 줘. 어떤 페이지(순위·카테고리·상세·검색 등)가 되고 각각 어떤 항목을 가져올 수 있는지 번호 붙은 표로 보여 줘. 아직 저장하지 마.
```

**확인할 것:** 표에 번호와 페이지마다 가져올 수 있는 항목이 나왔는지, `outputs`에 아직 아무 파일도 생기지 않았는지 봅니다. 인터넷 사용 승인 창이 뜨면 명령을 읽어 보고 승인합니다.

### ② 가져와서 정리

가장 쓸 만한 방법 하나로 상위 20개를 표로 모읍니다. 사이트에는 한 번만 요청합니다.

```text
가장 쓸 만한 방법 하나로 {수집 범위}를 가져와서 표로 정리해 outputs/수집.md로 저장해 줘. 항목마다 출처 링크를 붙이고, 사이트에는 한 번만 요청해 줘.
```

**확인할 것:** `outputs/수집.md`를 열어 표에 **상품명과 가격(네이버 증권은 종목명과 숫자)이 실제로 있는지** 봅니다. 빈 화면인데 성공이라고 하는 경우가 있습니다. 출처 링크 하나를 눌러 같은 이름이 보이는지 봅니다.

### ③ 분석 아이디어 (기획)

이 자료로 해 볼 분석 5개를 받고, 번호로 하나를 고릅니다.

```text
이 자료로 해 볼 수 있는 분석을 5개 제안해 줘. 분석마다 무엇을 비교하는지, 어떤 표나 그림이 나오는지 한 줄씩. 번호로 고를게.
```

**확인할 것:** 다섯 개가 모두 `수집.md`에 있는 숫자로 할 수 있는 것인지 봅니다. 마음에 드는 번호 하나를 보냅니다.

### ④ 자료 만들기

고른 분석으로 표 1개·그림 1개·결론 3줄 HTML 한 장을 만듭니다.

```text
{번호}번 분석으로 outputs/분석자료.html을 만들어 줘. 표 1개, 그림 1개, 결론 3줄. 파일 하나로 열리게 하고 인터넷에서 라이브러리나 글꼴을 불러오지 마. 출처는 맨 아래에 작게 넣고, 투자 관련 자료면 '투자 조언이 아님'도 넣어 줘.
```

**확인할 것:** `outputs/분석자료.html`을 더블클릭해 브라우저에서 표·그림·결론 3줄·맨 아래 출처가 보이는지 봅니다. 네이버 증권이면 맨 아래에 '투자 조언이 아님'이 있는지 봅니다.

### ⑤ 검토·개선

숫자 3개를 `수집.md`·출처 링크와 대조하고, 결과와 상관없이 한 곳만 바꿔 새 파일로 저장합니다. 결론 첫 줄 말고 다른 한 곳(예: 그림 색)을 바꾸고 싶으면 보낼 말의 그 부분만 원하는 내용으로 고쳐 보냅니다.

```text
분석자료.html의 숫자 3개를 outputs/수집.md와 출처 링크로 대조해서 맞는지 표로 보여 줘. 그다음 결과와 상관없이 결론 첫 줄 한 곳만 더 쉬운 말로 바꿔서 outputs/분석자료-v2.html로 저장해 줘. 다른 건 그대로.
```

**확인할 것:** 대조 표에 숫자 3개와 맞음/다름이 있는지, `분석자료.html`과 `분석자료-v2.html`을 나란히 열어 바뀐 곳이 한 곳뿐인지 봅니다. AI가 대조했어도 숫자 하나는 출처 링크를 직접 열어 내 눈으로 봅니다.

## 단계마다 지킬 것

- **결과부터 달라고 하지 않습니다.** "무엇을 가져올 수 있어?"부터 묻고, 분석도 제안을 받은 뒤 내가 고릅니다.
- **가져왔다고 믿지 않습니다.** 수집.md에 이름과 가격(숫자)이 실제로 있는지 봅니다.
- **사이트에는 꼭 필요한 만큼만 요청합니다.** 같은 페이지를 여러 번 부르지 않습니다.
- **네이버 증권은 투자 조언이 아닙니다.** 종목토론 글은 제목·날짜만, 개인 의견으로 따로 구분합니다. 사라·팔아라·오를 것 같은 말은 쓰지 않습니다.
- **고칠 때는 한 곳만, "다른 건 그대로".** 원래 파일도 남아 있는지 봅니다.

결과 문장은 사람마다 달라도 흐름과 남는 파일이 같으면 됩니다.

## 막히거나 늦을 때

| 상황 | 이렇게 합니다 |
|---|---|
| 사이트가 막혔다·빈 화면이다 | Codex가 한 줄로 알리고 `reference` 폴더의 예비 자료로 같은 단계를 이어 갑니다. 멈춰 있으면 `사이트가 막혔어. reference 폴더의 예비 자료로 같은 단계를 해 줘` |
| 크림에서 429(요청이 많다는 응답)가 난다 | 잠시 뒤 같은 요청문을 한 번만 다시 보냅니다. 그래도 안 되면 위 줄처럼 예비 자료로 |
| 막혔다 | `도와줘` |
| 시간이 모자란다 | `건너뛰기` — 모범 결과를 받아 다음 단계로 갑니다 |
| 어디까지 했는지 모르겠다 | `어디까지 했지` |

전체 권한(Full access)으로 바꾸자는 말이 나와도 바꾸지 않습니다.

## 추가: ego 브라우저로 해 보기

다섯 단계를 마치고 시간이 남는 사람만 합니다. insane-search는 사이트가 내주는 자료를 읽어서, 쿠팡 상품 상세처럼 차단이 센 곳은 막힙니다. ego는 화면에 브라우저를 띄워 사람처럼 열어 보기 때문에 이런 곳도 열립니다. 가입은 필요 없고, 회사 계정으로 로그인하지 않습니다.

### 1. ego 설치

1. [lite.ego.app](https://lite.ego.app/)에서 Windows 설치 파일을 받아 실행합니다. `Windows의 PC 보호` 창이 뜨면 **추가 정보** → **실행**을 누릅니다.
2. `이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?` 창이 뜨면 **예**를 누릅니다. 관리자 승인이 필요해 이 창에서 막히면(관리자 비밀번호를 묻는 경우) 여기서 멈추고 강사 화면을 봅니다.
3. ego가 열리면 첫 설정을 넘깁니다. **시작하기** → **다음** → **다음**. 데이터 가져오기 화면은 Chrome이 미리 체크돼 있으니 가져오지 말고 **나중에 설정**을 누릅니다. 소식 받아보기·알게 된 경로·기본 브라우저는 **건너뛰기**, 탭 스타일은 **다음**, 마지막에 **ego(lite) 열기**를 누릅니다.
4. ego 창은 열어 둡니다. Codex는 열려 있는 ego를 씁니다.
5. Codex 앱을 완전히 껐다가 다시 켜고, 같은 `2교시-Codex-리서치` 프로젝트에서 **새 채팅**을 엽니다.

**확인할 것:** ego 창이 떠 있고, Codex 입력창 위에 `2교시-Codex-리서치`가 보이는지 봅니다.

### 2. insane-search로 막힌 곳 열기

```text
ego 브라우저로 쿠팡 골드박스(오늘의 특가)를 열고 첫 번째 상품의 상세 페이지까지 들어가 줘. 상품명·가격·판매자·원재료나 주요 사양·리뷰 수를 outputs/ego-상세.md에 표로 저장하고 출처 링크를 붙여 줘.
```

명령 실행 승인 창이 뜨면 명령에 `ego-browser`가 있는지 보고 승인합니다. `ego 앱을 먼저 열어 두고 다시 보내 주세요`가 나오면 ego 창을 연 뒤 같은 문장을 다시 보냅니다.

**확인할 것:** ego 창에서 쿠팡 페이지가 열리는 게 보이는지, `outputs/ego-상세.md`에 판매자·원재료(또는 사양)가 있는지 봅니다.

### 3. 두 방법 비교

```text
같은 상품 상세를 insane-search로도 가져와 보고, ego 결과와 무엇이 다른지 표로 보여 줘. 파일은 만들지 마.
```

**확인할 것:** insane-search 쪽에서 막히거나 빠진 항목이 표에 보이는지 봅니다. 목록·순위처럼 사이트가 자료를 내주는 곳은 insane-search로 충분하고, 상세 화면·클릭·검색이 필요한 곳은 ego가 맞습니다.
