# 1교시 Codex 시작하기

> Codex를 처음 쓰는 분을 기준으로, 강사 화면을 보며 폴더 열기·첫 요청·다운로드 폴더 정리·플러그인 사용까지 하나씩 따라 합니다. 미리 해 보지 못한 분도 1교시에 함께 진행합니다.

---

## 1교시에서 배우는 순서

오늘은 강사 화면을 보며 **같이 하나씩 해 보는 시간**입니다. 본인의 다운로드 폴더를 써도 되고, 준비가 안 된 분은 안내 페이지의 예제 ZIP을 받아 같은 흐름으로 따라갑니다.

1. 교육 폴더를 프로젝트로 열기
2. 폴더의 역할 확인하기
3. 권한과 파일 생성 확인하기
4. 다운로드 폴더를 살펴보고 정리 계획 세우기
5. 플러그인 마켓플레이스 등록·설치·맛보기

각 단계는 **강사 화면을 보며 같이 진행**합니다. Codex에 보낼 요청문은 이 페이지에서 임의로 복사하지 않고, Codex가 현재 단계에서 보여 주는 안내 카드의 문장을 사용합니다.

## 1. 교육 폴더를 프로젝트로 열기

1. 과정 안내에서 받은 `tes-lab.zip`의 압축을 풉니다.
2. Codex 앱에서 **새 채팅**을 누릅니다.
3. 입력창 위 **프로젝트 선택**을 누르고 **새 프로젝트**를 선택합니다.
4. **추가**를 눌러 압축을 푼 `tes-lab` 폴더를 선택합니다.
5. 프로젝트 이름을 확인하고 **프로젝트 만들기**를 누릅니다.
6. 폴더 신뢰 화면이 나오면 경로가 `tes-lab`인지 확인하고 승인합니다.
7. 권한은 기본값인 **승인 요청**으로 둡니다.

## 2. 폴더의 역할 확인하기

프로젝트가 연결되면 대화창에 아래 한 문장만 보냅니다.

```text
@lab1
```

Codex가 1교시 진행 안내를 보여 주면, **그 안내에 따라 다음 요청을 하나씩 보냅니다.** 예를 들어 첫 안내가 다음처럼 나오면 그대로 보냅니다.

```text
이 폴더는 뭐 하는 곳이야?
```

이 폴더는 1교시와 2교시 실습 자료가 들어 있는 교육용 폴더입니다.

- `1교시-실습/`: 다운로드 폴더 정리와 첫 파일 만들기
- `2교시-연구소/`: 장비 런 데이터 분석 실습
- `2교시-운영/`, `2교시-재무/`: 혼합직무 과정용 자료
- `README.md`: 폴더 전체 사용 방법
- `.agents/skills/`: Codex가 반복 작업을 수행하는 방법

Codex의 안내 카드와 이 페이지의 순서가 다르면 **Codex 화면의 안내를 우선**하고 강사 화면을 따라갑니다.

## 3. 권한과 파일 생성 확인하기

Codex가 안내하는 파일 생성 요청을 그대로 따라 합니다. 예를 들어 아래와 같은 카드가 나오면 그 문장을 복사해 보냅니다.

```text
1교시-실습 폴더 안에 첫-확인.txt 파일을 만들어 줘. 파일에는 “Codex가 만든 첫 파일” 한 줄만 써 줘.
```

권한 창이 나오면 대상이 `tes-lab` 안인지 확인하고 승인합니다. 삭제·외부 전송·개인 폴더 접근을 요청하면 승인하지 말고 강사에게 알립니다.

## 4. 다운로드 폴더를 살펴보고 정리 계획 세우기

이번에는 안전한 교육 폴더 안에 작은 파일 하나를 만들어 봅니다. 파일을 만들기 전에 권한 확인 창이 뜨는지 살펴봅니다.

```text
1교시-실습 폴더 안에 첫-확인.txt 파일을 만들어 줘. 파일에는 “Codex가 만든 첫 파일” 한 줄만 써 줘. 만들기 전에 무엇을 할지 설명하고, 권한이 필요하면 창에서 확인할 수 있게 기다려 줘.
```

**예상 화면:** Codex가 파일을 만들겠다고 설명한 뒤 권한 승인 창을 보여 줄 수 있습니다. 승인 후 작업이 끝나면 파일 경로를 답합니다.

**확인할 것:**

- 권한 창에 표시된 대상이 교육 폴더인지
- 파일 이름이 `1교시-실습/첫-확인.txt`인지
- 파일을 직접 열었을 때 한 줄만 들어 있는지
- Codex가 말한 경로와 실제 파일 위치가 같은지

권한 창의 내용이 다르거나 삭제·외부 전송·개인 폴더 접근을 요청하면 **거부**를 누르고 강사에게 알립니다. 권한은 무조건 허용하는 버튼이 아닙니다. 무엇을 허용하는지 읽고 선택합니다.

## 플러그인 설치와 맛보기

플러그인은 Codex에 특정 작업 방법을 더해 주는 기능 묶음입니다. 먼저 강사 화면을 보며 마켓플레이스를 등록하고, 사용할 플러그인을 설치한 뒤 같은 요청을 보내 봅니다.

### 마켓플레이스 등록과 설치

1. 아래 주소를 복사합니다.

   **[GPTaku Codex 마켓플레이스](https://github.com/fivetaku/gptaku-plugins-codex)**

2. Codex의 플러그인 메뉴를 엽니다. 화면에 `/plugins`를 입력하거나 왼쪽 메뉴의 **Plugins**를 선택합니다.
3. **Marketplace 추가** 또는 **Add marketplace**를 선택합니다.
4. 방금 복사한 GPTaku Codex 마켓플레이스 주소를 붙여 넣고 등록합니다.
5. 등록된 마켓플레이스에서 **Insane Search Codex**, **Insane Research Codex**를 찾아 설치합니다.
6. 목록에 마켓플레이스가 보이지 않거나 등록에 실패하면 앱을 완전히 끄고 다시 켠 뒤 강사에게 알립니다.
7. 설치가 끝나면 **새 대화**를 엽니다. 설치한 플러그인은 새 대화에서 사용합니다.

> 플러그인 설치가 1교시 시간 안에 끝나지 않아도 괜찮습니다. 설치 과정을 함께 확인한 뒤, 막힌 분은 강사 시연을 보고 2교시 전 휴식 시간에 보조강사의 도움을 받습니다.

### 첫 번째 맛보기 — 공개 자료 찾기

`insane-search`는 잘 열리지 않는 공개 페이지나 뉴스의 내용을 찾아 읽는 용도입니다. 먼저 무엇을 하려는지 설명하고 요청합니다.

```text
지금은 공개 뉴스 1개를 찾아 실제로 열리는지 확인하는 연습을 합니다. insane-search로 오늘 반도체 장비 업계 뉴스 1개를 찾아 제목·날짜·한 줄 요약·주소를 표로 정리해 줘. 확인하지 못한 내용은 쓰지 마.
```

**예상 화면:** 검색 결과 표와 출처 주소가 나옵니다. 인터넷 사용 권한을 묻는 창이 나오면 강사와 같은지 확인합니다.

**확인할 것:** 주소를 눌렀을 때 실제 페이지가 열리는지, 표의 제목과 날짜가 페이지와 같은지 봅니다. 인터넷 결과는 반드시 원문과 대조합니다.

### 두 번째 맛보기 — 출처를 대조하는 짧은 조사

`insane-research`는 여러 출처를 대조해 짧은 보고서를 만드는 용도입니다.

```text
지금은 여러 출처를 비교하는 연습을 합니다. insane-research로 HBM 투자 확대가 증착 장비 수요에 미치는 영향을 출처 3개 이상으로 짧게 정리해 줘. 출처마다 확인한 주장과 주소를 함께 적고, 확실하지 않은 내용은 추정이라고 표시해 줘.
```

**예상 화면:** 짧은 설명과 출처 목록 또는 보고서 파일 경로가 나옵니다. 조사에 시간이 걸리면 강사 안내에 따라 멈추고 다음 단계로 갑니다.

**확인할 것:** 출처가 실제로 열리는지, 보고서의 주장과 출처가 연결되는지, 사실과 추정이 구분되는지 확인합니다.

요청문 앞에 `insane-search로`, `insane-research로`처럼 플러그인 이름을 쓰지 않으면 원하는 플러그인이 사용되지 않을 수 있습니다.

## 1교시가 끝나면

다음 항목을 직접 확인합니다.

- 교육 폴더 `tes-lab`를 Codex 프로젝트로 열었다.
- 본인 다운로드 폴더 또는 예제 ZIP 폴더를 열었다.
- 첫 요청을 보내고 Codex의 응답에서 한 일과 하지 않은 일을 구분했다.
- 권한 창의 대상과 파일 생성 결과를 확인했다.
- 다운로드 폴더를 살펴보고 정리 계획을 세웠다.
- 플러그인 마켓플레이스를 등록하고, 가능하면 플러그인 2개를 설치해 맛봤다.

플러그인이나 Codex 준비가 끝나지 않은 분은 1교시를 멈추고 기다리지 않습니다. 첫 휴식 시간에 보조강사의 도움을 받아 2교시를 시작할 수 있게 준비합니다.

마지막으로 처음 대화로 돌아가 `다음`을 보냅니다. 1교시에는 파일을 살펴보고 정리 계획을 세운 결과와 첫 확인 파일, 플러그인 사용 경험이 남습니다.
