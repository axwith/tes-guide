# 1교시 몸풀기와 플러그인

> 업무와 상관없는 다운로드 폴더 정리로 다섯 단계를 한 바퀴 돌고, 플러그인을 설치해 써 봅니다.

---

## 시작 전에 — 3교시 내 업무 공간 설치

강사 안내에 맞춰 1교시 처음에 아래 한 줄을 붙여 넣어 둡니다. 설치는 혼자 끝까지 진행되고, 3교시에 씁니다. **Codex 대화창이 아니라** PowerShell(Mac은 터미널)에 붙여 넣습니다.

**Windows** — 시작 메뉴에서 PowerShell을 열고 붙여 넣습니다.

```powershell
irm https://raw.githubusercontent.com/axwith/tes-workmate/main/get.ps1 | iex
```

**Mac** — 터미널을 열고 붙여 넣습니다.

```bash
curl -fsSL https://raw.githubusercontent.com/axwith/tes-workmate/main/install.sh | bash
```

설치가 끝나면 폴더가 열립니다(Windows `문서\tes-workmate`, Mac `~/Documents/tes-workmate`). 창은 그대로 두고 1교시를 이어 갑니다.

## 시작하기

1. 위 [과정 안내](#lab-0-01-overview)에서 실습 폴더(`tes-lab`)를 받아 압축을 풀어 둡니다.
2. Codex 앱에서 `tes-lab` 폴더를 프로젝트로 엽니다. 권한은 기본값 그대로 둡니다.
3. 대화창에 아래처럼 보냅니다.

```
1교시 시작
```

Codex가 1교시 전체 순서를 보여 줍니다. 그다음은 화면 안내대로 합니다. 설명을 읽고 `다음` → 요청문을 복사해 보내기 → 결과 확인 → `다음`.

## 다섯 단계

오늘 모든 실습은 사람이 일하는 순서와 같은 다섯 단계로 합니다.

| 단계 | 하는 일 |
|---|---|
| 1. 업무 파악 | "할 수 있어? 어떻게 해?"를 먼저 묻습니다 |
| 2. 기획 | 방법을 펼쳐 받고 내가 고릅니다. 계획을 파일로 남깁니다 |
| 3. 만들기 | 고른 계획대로 시킵니다 |
| 4. 검토 | "다시 검토해 줘"라고 하고, 숫자 하나는 내 눈으로 확인합니다 |
| 5. 개선 | 고칠 곳만 지정하고 "다른 건 그대로"라고 붙입니다 |

## 몸풀기 — 다운로드 폴더 정리

`1교시-몸풀기/downloads` 폴더에는 영수증·사진·설치 파일·문서가 섞인 가짜 파일 46개가 있습니다. 이 폴더를 다섯 단계로 정리합니다.

| 단계 | 보내는 요청문 | 확인할 것 |
|---|---|---|
| 업무 파악 | `1교시-몸풀기/downloads 폴더가 엉망이야. 정리하고 싶은데 어떻게 하면 좋을까? 먼저 어떤 파일이 몇 개 있는지 보고 알려 줘. 아직 아무것도 옮기지 마.` | 전체 개수와 종류별 개수가 나왔는지, 파일이 움직이지 않았는지 |
| 기획 | `좋아. 정리 계획을 1교시-몸풀기/계획.md로 저장해 줘. …` | 계획.md에 46개가 다 들어 있는지. 폴더 이름은 직접 고쳐도 됩니다 |
| 만들기 | `계획.md대로 정리해 줘. 파일은 지우지 말고 옮기기만 해. …` | 탐색기(Mac은 Finder)로 열어 폴더가 생겼는지 |
| 검토 | `다시 검토해 줘. 정리 전과 정리 후 파일 수가 같은지 …` | 정리결과.md가 생겼는지, 폴더 하나는 직접 열어 보기 |
| 개선 | `영수증 폴더만 파일 이름 앞에 날짜를 붙여서 … 다른 건 그대로.` | 영수증 폴더만 바뀌고 다른 폴더는 그대로인지 |

요청문 전체는 Codex 화면에 복사용으로 나옵니다. 마지막에 `중복 파일 지워 줘`를 보내 봅니다. Codex가 바로 지우지 않고 지울 목록과 번호 선택지를 보여 주면, `3`(그만두기)을 보내 거절합니다. 승인 창이 뜨면 **거부**를 누릅니다.

## 플러그인 설치하고 써 보기

플러그인은 Codex에 기능 묶음을 더하는 것입니다. 오늘은 두 개를 설치합니다.

| 플러그인 | 하는 일 |
|---|---|
| insane-search | 잘 안 열리는 공개 페이지·공시·뉴스를 여러 방법으로 열어 읽습니다 |
| insane-research | 출처를 대조하며 짧은 리서치 보고서를 씁니다 |

1. 대화창에 `/plugins`를 입력 → **GPTaku Codex** 선택 → **Insane Search Codex**, **Insane Research Codex** 설치. 목록에 GPTaku Codex가 없으면 앱을 완전히 끄고 다시 켭니다.
2. 왼쪽 위에서 **새 대화**를 엽니다. 플러그인은 새 대화부터 쓰입니다.
3. 새 대화에서 차례로 보냅니다.

```
insane-search로 오늘 반도체 장비 업계 뉴스 5개를 찾아서 제목·날짜·한 줄 요약·주소로 표로 정리해 줘
```

```
insane-research로 HBM 투자 확대가 증착 장비 수요에 어떤 영향을 주는지 출처 3개 이상으로 한 장 보고서 써 줘
```

```
방금 만든 파일 경로와 출처를 표로 보여 줘. 실제로 열어서 확인한 것만
```

**요청문 앞에 플러그인 이름(`insane-search로`, `insane-research로`)을 붙여야 플러그인이 쓰입니다.** 이름 없이 보내면 Codex 기본 웹 검색으로 답합니다.

확인할 것: 표의 주소 하나를 눌러 실제 기사가 열리는지, 날짜가 기사와 같은지. 인터넷 사용 승인 창이 뜨면 승인합니다. 보고서가 오래 걸리면 기다리지 말고 다음으로 넘어갑니다. 결과는 나중에 `RESEARCH` 폴더에서 볼 수 있습니다.

다 하면 처음 대화로 돌아가 `다음`을 보냅니다. 마지막 정리 요청까지 하면 `1교시-몸풀기/1교시-정리.md`가 남습니다.
