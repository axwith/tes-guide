# 막혔을 때

> 혼자 오래 붙잡지 말고 바로 손을 들어 주세요.

---

## 먼저 할 일

1. **손을 들어 강사나 보조강사를 부릅니다.** 화면을 같이 보면서 풉니다.
2. 기다리는 동안 Codex 대화창에 아래 말을 보내 볼 수 있습니다.

| 상황 | 보내는 말 |
|---|---|
| 무엇을 해야 할지 모르겠다 | `도와줘` |
| 시간이 모자란다 | `건너뛰기` — 모범 결과를 받아 다음으로 갑니다 |
| 어디까지 했는지 모르겠다 | `어디까지 했지` |
| 묻지 않은 일까지 했다 | `요청한 것만 해 줘` |
| 다른 부분까지 바뀌었다 | `지정한 것 말고는 이전 파일과 똑같이 되돌려 줘` |

---

## 자주 막히는 곳

| 증상 | 할 일 |
|---|---|
| `/lab1`을 보냈는데 안내가 안 나온다 | Codex에서 연 폴더가 `tes-lab`인지 확인합니다. 압축을 푼 폴더 안에 `tes-lab` 폴더가 한 번 더 있으면 안쪽 폴더를 엽니다 |
| 승인 창이 떴는데 무엇인지 모르겠다 | 창의 명령 첫 줄을 읽습니다. 작업 폴더 안 일이면 승인, 지우기면 거부합니다. 모르겠으면 손을 듭니다 |
| `/plugins`에 GPTaku Codex가 없다 | 앱을 완전히 끄고 다시 켭니다. 그래도 없으면 강사 화면 시연을 봅니다 |
| 플러그인 이름을 넣었는데 쓰이지 않는다 | 설치 뒤 **새 대화**에서 보냈는지 확인합니다 |
| Windows에서 insane-search가 오류를 낸다 | 강사 화면 시연으로 넘어갑니다. 같은 요청을 플러그인 이름 없이 보내 기본 웹 검색으로 해 봐도 됩니다 |
| 회사망에서 플러그인 설치가 막힌다 | 설치는 건너뛰고 강사 화면 시연을 봅니다 |
| 대시보드 HTML이 빈 화면이다 | `차트 값을 미리 계산해 HTML 안에 넣어서 다시 만들어 줘. 새 이름으로 저장` |
| 영수증 날짜가 전부 오늘 날짜로 나온다 | 압축이 아닌 다른 방법으로 받은 경우입니다. `파일 이름에 날짜가 있는 것만 바꿔 줘. 다른 건 그대로` |
| 3교시 Codex 활용하기 폴더가 없다 | [1교시 안내](#mixed-1-01-warmup)의 설치 한 줄을 다시 붙여 넣습니다. 끝나지 않으면 손을 듭니다 |

설치·로그인·모델 선택처럼 앱 자체 문제는 [설치 안내의 막혔을 때](/#ref-troubleshooting)도 봐 주세요.
