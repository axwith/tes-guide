# 3교시 Codex 활용하기

> 강사가 한 단계씩 먼저 보여 주고, 모두 같은 문장과 같은 번호를 보냅니다. 모두 같은 예시 자료(`2026-11_검사결과.csv`)로 업무 보고서를 만든 뒤, 같은 폴더에서 숫자 점검·회의 준비·스킬 만들기·새 채팅 기억 확인·정리를 같이 해 봅니다. PPT 초안은 강사 화면으로 봅니다.

---

## 내 업무 공간이란

`tes-workmate`는 내 업무를 위한 Codex 작업 폴더입니다. 설치할 때 이 PC에서 최근에 쓰던 업무 파일의 목록과 본문을 미리 읽어 두고, 온보딩에서 그 내용으로 내 업무를 확인합니다. 쓸수록 기록·규칙·스킬이 쌓입니다.

- 분석은 내 PC의 Codex 안에서만 합니다. 파일을 밖으로 보내지 않습니다.
- 오늘은 모두 설치본에 들어 있는 가상 예시 자료로 연습합니다. 실제 회사·인물과 관계없는 자료입니다.
- 회사 정보는 공개 자료로 만든 것이라 사내 사정과 다를 수 있습니다.
- 이름·소속은 파일에서 짐작하지 않고, 온보딩에서 내가 직접 입력한 값만 씁니다.

1교시에 설치하지 못했다면 1단계에서 설치 한 줄을 붙여 넣습니다.

---

## 순서 — 강사와 같이

단계마다 강사 화면과 내 화면이 같아지면 손을 듭니다. 막히면 옆 사람 화면을 보고, 다음 단계부터 다시 같이 합니다. 승인 방식은 **승인 요청** 그대로 두고 **전체 권한**으로 바꾸지 않습니다.

### 1. 설치 확인

휴식 시간에 설치한 창에 `설치 완료:`가 보이면 됩니다. `문서\tes-workmate`(OneDrive를 쓰면 `OneDrive\문서\tes-workmate`) 폴더가 있는지 봅니다. 지금은 이 폴더에 내 파일을 넣지 않습니다.

설치하지 않았다면 지금 붙여 넣습니다.

시작 메뉴에서 `PowerShell`을 찾아 **Windows PowerShell**을 열고 붙여 넣은 뒤 Enter를 누릅니다.

```powershell
irm https://raw.githubusercontent.com/axwith/tes-workmate/main/get.ps1 | iex
```

`기본 검색에 더할 업무 폴더 경로`를 물으면 아무것도 넣지 말고 Enter를 누릅니다.

**확인할 것:** 마지막에 `설치 완료:`와 `다음:` 안내가 보이고 폴더 창이 열리는지 봅니다. `기억 자동 정리 등록에 실패했습니다`가 보여도 설치는 끝난 것입니다.

### 2. 폴더 열기

1. Codex 앱 왼쪽 위 **새 채팅**을 누릅니다.
2. 입력창 바로 위 **프로젝트 선택** → 목록 맨 아래 **새 프로젝트** → **추가**를 누릅니다.
3. **문서**(OneDrive를 쓰면 `OneDrive\문서`)에서 `tes-workmate`를 한 번 눌러 고르고 **폴더 선택**을 누릅니다. 폴더 안으로 들어가서 고르지 않습니다.
4. 프로젝트 이름이 `tes-workmate`인지 보고 **프로젝트 만들기**를 누릅니다.
5. 폴더를 신뢰할지 물으면 경로 끝이 `tes-workmate`인지 보고 **폴더 신뢰**를 누릅니다.

**확인할 것:** 입력창 바로 위에 `tes-workmate`가 보이는지 봅니다. `tes-lab`이 보이면 다른 폴더를 연 것입니다.

### 3. `@onboard`로 시작하기 — 자료는 3번

대화창에 아래 한 줄을 보냅니다.

```text
@onboard
```

자료 범위 번호가 나오면 오늘은 모두 `3`(가상 예시 자료로 연습)을 보냅니다. 자료를 볼 범위를 한 번 더 물으면 그때도 `3`을 보냅니다.

인사와 업무 선택지만 나오고 자료 범위 질문이 없으면 `@onboard`를 한 번 더 보냅니다.

**확인할 것:** 이름·소속을 묻는 화면으로 넘어갔는지 봅니다. 목록에 모르는 파일이나 개인정보·사내 기밀 파일이 보이면 쓰지 말고 강사에게 알립니다.

### 4. 이름·소속과 첫 결과물 종류

강사가 번호를 불러 주면 같이 보냅니다.

1. 이름·소속: `1`을 보낸 뒤 `홍길동 / 품질팀`처럼 내 이름과 소속을 한 줄로 보냅니다. 이름을 넣고 싶지 않으면 `3`을 보냅니다.
2. 업무·반복 주기·보고 대상·회사 맥락: 강사가 부르는 번호를 보냅니다(예: 업무 `1` 월간 품질 보고, 반복 주기와 보고 대상이 한 화면에 나오면 `3, 1`처럼 한 줄로, 회사 맥락 `1` 공개 자료).
3. 첫 결과물 종류: 모두 `4`(업무 보고서)를 보냅니다. PPT는 7단계에서 강사가 보여 줍니다.

**확인할 것:** 첫 결과물 계획과 `1. 계획 승인` 선택지가 보이는지 봅니다.

### 5. 계획 승인하고 업무 보고서 만들기

계획을 훑어보고 아래 한 글자를 보냅니다.

```text
1
```

승인했다는 답만 나오고 파일이 생기지 않으면 `만들어 줘`를 보냅니다. 권한 창이 뜨면 대상이 `tes-workmate` 안인지 보고 승인합니다.

보고서가 예시 자료를 쓰지 않았거나 비어 있으면 아래를 보냅니다.

```text
.agents/skills/prescan/sample/pc/문서/품질보고/2026-11_검사결과.csv 와 같은 폴더의 2026-10_월간품질보고.md 를 원자료로, 방금 계획대로 업무 보고서 초안을 만들어 줘. 원자료에 없는 숫자나 사실은 넣지 말고, 확인이 필요한 부분은 [확인 필요]로 표시해 줘. 저장한 파일 경로를 알려 줘.
```

**확인할 것:** 답에 나온 경로를 눌러 보고서를 직접 열었는지 봅니다.

### 6. 숫자 확인과 검토

강사 화면의 `2026-10_월간품질보고.md`에서 "검사 수 500, 불량 20, 불량률 4.0%"를 보고, 내 보고서의 같은 숫자가 맞는지 눈으로 확인합니다.

```text
초안을 검토해 줘. 빠진 내용·원자료와 다른 내용·읽기 어려운 표현을 각각 표로 보여 줘. 아직 파일은 고치지 마.
```

**확인할 것:** 검토 표가 나오고 보고서 파일은 바뀌지 않았는지 봅니다.

### 7. 규칙 한 줄 남기기

```text
앞으로 표의 비율 차이는 항상 %p로 적어 줘
```

**확인할 것:** `AGENTS.md` 5장에 규칙이 들어갔다는 답이 나오는지 봅니다.

## 같이 해 보기 — 내 업무 공간으로 할 수 있는 일

업무 보고서를 만든 채팅에서 이어서 합니다. 단계마다 강사 화면과 같아지면 손을 듭니다.

### 8. 숫자 다시 계산하기

```text
@cross-check 방금 만든 보고서 숫자 맞는지 봐 줘
```

**확인할 것:** 답에 `120 + 110 + 130 + 140 + 100 = 600건`처럼 원자료를 다시 더한 계산이 보이고, 보고서 파일은 바뀌지 않았는지 봅니다.

### 9. 다음 회의 준비하기

```text
@meeting-brief 다음 주 품질 회의 준비해 줘
```

**확인할 것:** 안건 3개에 스크래치 9건, 불량률 3.0%가 출처 파일 이름과 함께 나오고, `reports/`에 회의 준비 파일이 생겼는지 봅니다. 회의 날짜는 Codex가 정한 것이라 `확인 필요`로 나옵니다.

### 10. 오늘 한 보고서를 스킬로 만들기

같은 채팅에서 보냅니다.

```text
방금 만든 월간 품질 보고서 순서를 스킬로 만들어 줘
```

권한 창이 뜨면 대상이 `tes-workmate` 안인지 보고 승인합니다.

**확인할 것:** `AGENTS.md` 6장 표에 방금 만든 스킬 줄이 생겼는지 봅니다.

### 11. 새 채팅에서 기억 확인하기

1. Codex 앱 왼쪽 위 **새 채팅**을 누릅니다.
2. 입력창 바로 위 프로젝트가 `tes-workmate`인지 봅니다.

```text
지난번에 비율 차이 어떻게 적기로 했지?
```

**확인할 것:** 앞 채팅에서 남긴 `%p` 규칙을 답하는지 봅니다.

### 12. 만든 스킬을 한 마디로 부르기

11단계의 새 채팅에서 이어서 보냅니다.

```text
예시 자료로 이번 달 월간 품질 보고서 만들어 줘
```

**확인할 것:** 새 보고서에 검사 600건, 불량 18건, 불량률 3.0%가 나오는지 봅니다. 교육 뒤에 내 자료를 넣은 다음에는 `예시 자료로`를 빼고 `이번 달 월간 품질 보고서 만들어 줘`라고만 보냅니다.

### 13. 정리해 줘

```text
정리해 줘
```

**확인할 것:** `memory/daily/` 오늘 날짜 파일을 열어 숫자 점검·회의 준비·스킬 만들기·새 채팅에서 한 일이 적혔는지 봅니다. 답에는 마지막 채팅의 일만 나올 수 있으니 파일로 확인합니다.

### 14. PPT 초안 — 강사 시범

강사가 같은 예시 자료로 TES 공통 템플릿 PPT 초안을 만듭니다. 만드는 데 5~10분쯤 걸려, 강사가 8단계를 시작할 때 다른 채팅에서 미리 돌려 두고 여기서 완성본을 같이 봅니다. 강사 PPT가 일찍 열리면 해 보고 싶은 사람만 같은 문장을 보냅니다.

```text
@ppt-draft .agents/skills/prescan/sample/pc/문서/품질보고/2026-11_검사결과.csv 와 같은 폴더의 2026-10_월간품질보고.md 를 원자료로, 팀장 보고용 PPT 초안 만들어 줘. 설명에 도움이 되는 그림이 있으면 생성해서 넣어 줘.
```

슬라이드 계획이 나오면 `1`(계획 승인)을 보냅니다. 파일이 생기지 않으면 `만들어 줘`를 보냅니다.

**확인할 것:** 만든 PPTX가 `reports/`에 저장되고 PowerPoint에서 열리는지, 숫자 하나가 원자료와 같은지, 생성 그림 아래에 `이미지: AI 생성`이 적혔는지 강사 화면으로 봅니다. "PPT 도구를 준비하지 못해 보고서로 만듭니다"가 나오면 그 보고서로 마칩니다. 수업 중에 설치를 다시 하지 않습니다.

## 교육 뒤에 쓰는 세 마디

| 이럴 때 | 이렇게 말합니다 |
|---|---|
| 일이 끝났을 때 | `정리해 줘` |
| 고쳐 주고 싶은 점이 있을 때 | `앞으로 항상 …` |
| 같은 일을 또 할 때 | `스킬로 만들어 줘` |

내 업무 공간은 교육이 끝난 뒤에도 그대로 씁니다. 내 업무 파일은 교육이 끝난 뒤 넣고, 자료를 더 넣고 싶으면 `최근 파일 더 모아 줘`라고 보냅니다.

## 교육 뒤에 매일 쓰는 법

설치된 `tes-workmate` 폴더에는 아래 폴더가 있습니다. 파일을 넣을 때와 일을 시킬 때 이 표를 봅니다.

| 폴더 | 넣는 것 | Codex에 이렇게 말합니다 |
|---|---|---|
| `00-inbox` | 새로 받은 파일(메일 첨부, 다운로드). 어디 둘지 모르면 일단 여기 | `인박스 정리해 줘` |
| `10-projects` | 기간이 있는 일(과제·프로젝트). 일마다 폴더 하나 | `10-projects에 ○○ 과제 폴더 만들고 인박스 자료를 옮겨 줘` |
| `20-operations` | 반복 업무(주간·월간 보고, 정기 점검). 업무마다 폴더 하나 | `이번 달 월간 보고 만들어 줘` |
| `30-knowledge` | 배운 것, 정리해 둘 지식 | `오늘 알게 된 내용을 30-knowledge에 정리해 줘` |
| `40-personal` | 개인 메모, 할 일 | `할 일에 ○○ 추가해 줘` |
| `50-resources` | 밖에서 받은 참고 자료(규격서, 매뉴얼) | `50-resources의 규격서 기준으로 맞는지 봐 줘` |
| `90-archive` | 끝난 일 | `끝난 ○○ 과제 폴더를 90-archive로 옮겨 줘` |
| `references` | 기준값, 보고서 양식, 용어집 | `이 양식을 앞으로 보고서 양식으로 써 줘` |
| `reports` | Codex가 만든 결과물. 직접 넣지 않습니다 | `지난주에 만든 보고서 열어 줘` |
| `memory` | Codex의 기억(작업 기록·규칙 후보). 직접 고치지 않습니다 | `지난번에 어떻게 하기로 했지?` |

매일 쓰는 말은 다섯 가지입니다.

| 이럴 때 | 이렇게 말합니다 |
|---|---|
| 일이 끝났을 때 | `정리해 줘` — 한 일과 고친 점이 `memory/daily/`에 남습니다 |
| 고쳐 주고 싶은 점이 있을 때 | `앞으로 항상 …` — `AGENTS.md` 5장 규칙이 됩니다 |
| 같은 일을 또 할 때 | `스킬로 만들어 줘` — 다음부터 한 마디로 같은 순서를 밟습니다 |
| 어제 하던 일을 이어 할 때 | **새 채팅**에서 프로젝트를 `tes-workmate`로 고르고 `지난번에 하던 ○○ 이어서 해 줘` |
| ChatGPT에서 하던 일을 더 가져올 때 | `@chatgpt-import 견적 비교 대화 찾아서 가져와 줘` — 주제에 맞는 대화를 찾아 읽고, 내 업무·반복 업무·규칙을 뽑아 내가 승인한 것만 저장합니다. 온보딩(`@onboard`) 때는 최근 대화를 묻지 않고 먼저 훑어 업무 후보로 보여 줍니다 |

ChatGPT 대화는 Codex 앱에 로그인한 ChatGPT 계정에서 읽습니다. 읽지 못하면 ChatGPT **설정 → 데이터 제어 → 데이터 내보내기**로 받은 ZIP 파일을 `00-inbox`에 넣고 `ChatGPT 내보내기 파일 넣었어`라고 보냅니다. 개인정보와 고객사 이름은 가린 채로 저장합니다.
