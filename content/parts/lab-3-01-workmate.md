# 3교시 내 업무 공간

> 1교시에 설치해 둔 내 업무 공간을 열어, 내 업무를 알려 주고 2교시 분석을 내 스킬로 만든 뒤 내 업무 한 건을 해 봅니다.

---

## 내 업무 공간이란

`tes-workmate`는 내 업무를 위한 Codex 작업 폴더입니다. 설치할 때 이 PC에서 최근에 쓰던 업무 파일을 읽어 내 업무에 맞게 미리 세팅되고, 쓸수록 기록·규칙·스킬이 쌓입니다.

- 분석은 내 PC의 Codex 안에서만 합니다. 파일을 밖으로 보내지 않습니다.
- 최근 업무 파일이 거의 없으면 직무별 가상 예시 자료로 세팅됩니다.
- 회사 정보는 공개 자료로 만든 것이라 사내 사정과 다를 수 있습니다.

1교시에 설치하지 못했다면 지금 [1교시 안내](#lab-1-01-warmup)의 설치 한 줄을 붙여 넣습니다.

---

## 열기

1. Codex 앱에서 내 업무 공간 폴더를 프로젝트로 엽니다.
   - Windows: `문서\tes-workmate`
   - Mac: `~/Documents/tes-workmate`
2. 대화창에 보냅니다.

```
안녕하세요
```

## 따라 하기

| 순서 | 보내는 말 | 확인할 것 |
|---|---|---|
| 1. 온보딩 | `온보딩 해 줘` | Codex가 추정한 직무·보고 대상·반복 업무를 번호 선택지로 묻습니다. 번호로 고르고, 이름과 소속을 답합니다 |
| 2. 전후 비교 | `내가 무슨 일 하는지 알아?` | 온보딩 전보다 내 업무를 구체적으로 말하는지 |
| 3. 회사 질문 | `우리 회사 주력 장비가 뭐고, 내 부서는 그 안에서 어떤 일을 하는지 3줄로` | 답에 근거 문서 링크가 있는지 |
| 4. 내 스킬 만들기 | `2교시에 한 분석 절차를 내 공간 스킬로 만들어 줘` | 입력·결과물·규칙·완료 기준 네 가지를 묻거나 채우는지, `.agents/skills/`에 새 스킬이 생겼는지 |
| 5. 스킬 써 보기 | `방금 스킬로 다른 기간 자료도 해 줘` | 두 번째 결과가 같은 순서로 나오는지 |
| 6. 규칙 남기기 | `앞으로 그래프 제목에는 항상 기간을 넣어 줘` | `AGENTS.md` 5장에 규칙이 들어갔는지 |
| 7. 정리 | `정리해 줘` | 오늘 한 일이 기록으로 남았는지 |

---

## 각자 — 내 업무 한 건

마지막은 각자 합니다.

1. 내 업무 하나를 말로 시킵니다. 첫 인사 답에 나온 업무 선택지에서 골라도 됩니다.
2. 결과 파일을 직접 열어 봅니다.
3. 숫자나 사실 하나를 원자료와 대조합니다.
4. 고칠 점 하나를 말로 요청합니다. 고칠 곳만 지정하고 "다른 건 그대로"를 붙입니다.

결과 파일 하나가 남으면 됩니다.

## 내 업무 공간에 쌓이는 곳

| 오늘 한 일 | 쌓이는 곳 |
|---|---|
| 내 업무·이름·소속 | `AGENTS.md` 4장 |
| 회사·업계 정보 | `memory/wiki/domain-context/` |
| 결과물 | `reports/` |
| "앞으로 항상" 규칙 | `AGENTS.md` 5장 |
| 만든 스킬 | `.agents/skills/`, `AGENTS.md` 6장 |
| 작업 기록, 스킬로 만들 만한 반복 작업 | `memory/daily/`, `memory/candidates.md` |

## 교육 뒤에 쓰는 세 마디

| 이럴 때 | 이렇게 말합니다 |
|---|---|
| 일이 끝났을 때 | `정리해 줘` |
| 고쳐 주고 싶은 점이 있을 때 | `앞으로 항상 …` |
| 같은 일을 또 할 때 | `스킬로 만들어 줘` |

내 업무 공간은 교육이 끝난 뒤에도 그대로 씁니다. 자료를 더 넣고 싶으면 `최근 파일 더 모아 줘`라고 보냅니다.
