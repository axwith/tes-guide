# 시간이 남으면 — 내 자료로 선택 실습

> 교육 폴더의 가상 자료로 먼저 연습한 뒤, 시간이 남으면 참가자가 가져온 공개·교육 허용 자료를 읽혀 설명·요약·질문을 해 봅니다. 이 실습은 선택 사항입니다.

## 먼저 지킬 것

- 교육용 가상 자료를 우선 사용합니다. 자기 자료를 쓸 때는 **공개 자료이거나 교육에서 사용해도 된다고 확인한 자료만** 가져옵니다.
- 개인정보, 고객 정보, 사내 기밀, 미공개 연구자료, 접근 권한이 필요한 자료, 계약상 외부 반출이 금지된 자료는 사용하지 않습니다.
- 원본 파일은 그대로 둡니다. 복사본을 교육 폴더에 넣고, 요청에도 `원본을 수정하지 마세요`를 적습니다.
- 파일을 읽는 것과 파일을 고치는 것은 다릅니다. 처음에는 읽기·설명·요약·질문 답변만 시킵니다.
- 결과에 원문에 없는 내용을 보태지 않도록 `근거가 없으면 모른다고 말하고, 근거가 된 파일과 쪽 또는 절을 함께 알려 주세요`라고 요청합니다.

## 어떤 자료를 고를까요

참가자의 직무에 맞는 자료 하나만 고릅니다. 문서가 길면 5~10쪽 또는 표 한 개 정도로 시작합니다.

| 참가자 | 고를 수 있는 자료 | 해 볼 일 |
|---|---|---|
| 연구개발 | 공개된 개발자료, 시험결과 예시, 설계검토 자료 | 자료의 목적과 조건 설명, 결과 요약, 이상값·확인할 질문 찾기 |
| 혼합직무 | 공개 업무문서, 교육용 업무문서, 회의자료 | 핵심 결정사항 요약, 담당자·기한·미결사항 정리, 다음 회의 질문 만들기 |

예를 들어 연구개발 참가자는 공개 시험결과 표나 교육용 설계검토 문서를, 혼합직무 참가자는 공개 회의자료나 교육용 업무보고서를 선택합니다. 실제 업무를 재현하기보다, 자료를 읽고 확인할 질문을 만드는 데 초점을 둡니다.

## 초보자 순서

### 1. 복사본을 만듭니다

1. 사용할 파일을 탐색기(Windows) 또는 Finder(Mac)에서 찾습니다.
2. 파일을 복사합니다. 원래 폴더의 파일을 끌어 옮기지 않습니다.
3. 교육 폴더 안에 `선택-실습` 폴더를 만들고 복사본을 붙여 넣습니다.
4. 파일 이름에 개인정보나 회사 기밀이 남아 있지 않은지 다시 확인합니다.

파일을 넣는 방법을 모르겠으면 강사에게 먼저 보여 주세요. 공유 드라이브나 메일 첨부파일을 직접 연결하지 말고, 교육 폴더에 복사한 파일만 사용합니다.

### 2. 작업 폴더에 파일을 추가합니다

1. 앱에서 교육 프로젝트를 엽니다.
2. 프로젝트의 소스 폴더가 `codex-교육`인지 확인합니다.
3. 탐색기 또는 Finder에서 `codex-교육/선택-실습` 폴더를 엽니다.
4. 복사한 파일을 그 폴더 안에 넣습니다.
5. 앱의 파일 목록을 새로 고치거나 새 대화를 열어 파일이 보이는지 확인합니다.

처음에는 파일 하나만 넣습니다. 여러 파일을 넣을 때는 서로 어떤 관계인지 알 수 있도록 같은 주제의 자료만 고릅니다.

### 3. 먼저 파일 목록만 확인합니다

아래 요청을 보내 파일을 실제로 읽을 수 있는지 확인합니다.

```text
선택-실습 폴더에 있는 파일 이름과 파일 형식을 알려 주세요.
아직 파일을 수정하거나 새 파일을 만들지 마세요.
```

파일 이름이 보이지 않으면 파일이 `codex-교육/선택-실습` 안에 있는지 다시 확인합니다. 파일이 열리지 않을 때는 형식을 바꾸거나 원본을 다시 저장하지 말고 강사에게 알립니다.

### 4. 파일을 쉬운 말로 설명하게 합니다

```text
선택-실습 폴더의 파일을 읽고, 이 자료가 무엇을 위한 것인지 초보자도 이해할 수 있게 설명해 주세요.
설명마다 근거가 된 파일 이름과 쪽·절·표를 함께 적어 주세요.
원본 파일은 수정하지 마세요.
```

답을 읽으면서 다음을 확인합니다.

- 자료의 목적과 대상이 맞는가?
- 설명마다 파일 안의 근거가 있는가?
- 모르는 내용을 추측하지 않았는가?
- 원본 파일을 수정하거나 새 파일을 만들지 않았는가?

### 5. 요약을 요청합니다

자료의 종류에 따라 아래 요청 중 하나를 보냅니다.

**연구개발 자료**

```text
이 자료를 다음 순서로 요약해 주세요.
1. 개발·시험·설계검토의 목적
2. 사용한 조건과 범위
3. 주요 결과
4. 결과에서 바로 확인할 수 없는 점
5. 연구자가 다음에 확인할 질문 3개
각 항목에 근거가 된 파일 이름과 쪽·절·표를 붙이고, 원본은 수정하지 마세요.
```

**혼합직무 자료**

```text
이 업무문서 또는 회의자료를 다음 순서로 요약해 주세요.
1. 이번 자료의 목적
2. 결정된 사항
3. 담당자와 기한
4. 아직 정해지지 않은 사항
5. 다음 회의나 업무에서 물어볼 질문 3개
자료에 없는 담당자·기한은 추측하지 말고 '자료에 없음'이라고 적어 주세요.
원본은 수정하지 마세요.
```

### 6. 질문을 이어서 보냅니다

요약을 그대로 믿지 말고, 자료를 확인하는 질문을 하나 더 보냅니다.

```text
방금 요약에서 가장 확실한 근거가 있는 주장 2개와 추가 확인이 필요한 주장 2개를 나눠 주세요.
각 주장 옆에 근거 파일의 쪽·절·표를 적어 주세요.
자료에 없는 내용은 추측하지 마세요.
```

이어서 참가자가 직접 질문을 하나 만듭니다. 예를 들면 다음과 같습니다.

- `시험 조건 중 결과에 가장 큰 영향을 줄 수 있는 조건은 무엇이며, 자료의 어디에 근거가 있나요?`
- `설계검토에서 아직 답하지 않은 위험 요소를 찾아 주세요.`
- `회의에서 결정된 일과 논의만 된 일을 구분해 주세요.`
- `다음 회의 전에 확인해야 할 질문을 우선순위 순서로 정리해 주세요.`

## 결과 확인과 마무리

1. 답변에서 파일 이름과 쪽·절·표를 따라가며 주장 하나를 원자료와 대조합니다.
2. 원본 파일의 수정 시각이나 내용이 바뀌지 않았는지 확인합니다.
3. 잘못 읽은 부분이 있으면 자료를 직접 고치지 말고 다음처럼 다시 묻습니다.

```text
방금 답변의 2번은 원자료와 맞지 않는 것 같습니다.
원자료의 표 1만 다시 확인하고, 맞는 내용과 근거를 알려 주세요.
파일은 수정하지 마세요.
```

4. 시간이 남고 결과를 저장해야 할 때만 다음처럼 별도 메모를 만듭니다.

```text
지금까지의 설명과 요약을 `선택-실습/읽기-메모.md`에 정리해 주세요.
원본 파일은 수정하지 말고, 메모에는 오늘 읽은 파일 이름과 근거 위치를 적어 주세요.
```

파일 만들기 승인 창이 나타나면 대상 경로가 `codex-교육/선택-실습` 안인지 확인한 뒤 승인합니다. 원본 파일을 덮어쓰거나 폴더 밖에 저장하려는 요청이면 승인하지 않습니다.

## 시간이 부족하거나 자료 사용이 애매할 때

자료를 고르는 데 시간이 걸리거나 사용 가능 여부가 확실하지 않으면 자기 자료를 넣지 않습니다. 교육 폴더의 가상 자료로 다음 요청을 보내고 마칩니다.

```text
교육 폴더의 가상 자료를 읽고, 자료의 목적을 설명한 뒤 확인할 질문 3개를 만들어 주세요.
파일은 수정하거나 새로 만들지 마세요.
```

이 실습의 목표는 개인 자료를 많이 처리하는 것이 아니라, **파일을 복사본으로 추가하고, 읽기 요청을 구체적으로 보내고, 근거와 원본 보존 여부를 확인하는 순서**를 익히는 것입니다.
