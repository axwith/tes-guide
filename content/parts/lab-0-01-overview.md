# 연구소 과정 안내

> 당일 순서와 실습 폴더 받는 방법입니다. 각 교시는 **Codex 시작하기 → Codex 응용하기 → Codex 활용하기** 순서로 진행합니다.

---

## 오늘 순서

1회차 11월 24일(화), 2회차 11월 25일(수). 두 회차는 같은 내용입니다.

| 교시 | 하는 일 | 끝나면 남는 것 |
|---|---|---|
| 1교시 **Codex 시작하기** | 강사 화면을 보며 사람이 일하는 다섯 단계, Codex가 일하는 방식, 폴더 열기·첫 요청·응답 읽기·권한 확인·다운로드 폴더 정리·플러그인 설치와 맛보기를 함께 진행합니다 | 정리 계획, 첫 확인 파일, 플러그인 사용 경험 |
| 2교시 **Codex 응용하기** | CVD 공정 데이터를 같은 다섯 단계로 분석하고, 대시보드와 한 장 보고를 만듭니다 | 분석 표, 대시보드, 한 장 보고 |
| 3교시 **Codex 활용하기** | 미리 읽어 둔 내 업무 파일로 내 업무 공간(`tes-workmate`)을 온보딩하고, 2교시 분석을 내 스킬로 만든 뒤 각자 내 업무 한 건 | 내 업무 공간, 결과 파일 1개 |

강사 화면을 보며 같은 순서로 따라 합니다. 결과 문장은 사람마다 달라도 흐름과 남는 파일이 같으면 됩니다. 2교시 실습은 CVD 공정 데이터(가상 증착 장비의 런 기록과 웨이퍼 두께 데이터)로 진행합니다.

---

## 1교시 실습 자료 받기

1교시는 모두 같은 예제 파일로 진행합니다. 강사 화면을 보며 함께 압축을 풀고, 같은 `tes-lab` 폴더를 엽니다.

영수증·회의 자료·사진·설치 파일·압축 파일·중복 파일처럼 실제 다운로드 폴더에 있을 법한 가상 자료가 들어 있습니다. 모든 파일은 교육용 가상 자료입니다.

**[예제 다운로드 폴더 받기 (tes-lab.zip)](/downloads/tes-lab.zip)**

1. 위 링크로 `tes-lab.zip`을 받습니다.
2. 압축을 풉니다.
   - Windows: 받은 파일을 오른쪽 클릭 → **모두 압축 풀기** → 바탕 화면을 고르고 **압축 풀기**
   - Mac: 받은 파일을 더블클릭하고, 생긴 `tes-lab` 폴더를 바탕 화면으로 옮깁니다.
3. `tes-lab` 폴더 안에 `1교시-실습`, `2교시-…` 폴더와 `README.md`가 보이면 됩니다.

**Codex 앱은 교육 전에 설치하고 로그인해 둡니다.** `tes-lab` 예제 ZIP은 1교시를 시작할 때 함께 내려받아도 됩니다. 강사 화면을 보며 압축을 풀고 폴더를 여는 것부터 진행합니다.

## Codex에서 폴더 열기

1. ChatGPT 데스크톱 앱을 열고 왼쪽 위가 **Codex**인지 확인합니다.
2. **새 채팅**을 먼저 누릅니다.
3. 새 채팅에서 `tes-lab` 폴더를 프로젝트로 엽니다. 방법이 기억나지 않으면 [작업 폴더 연결과 첫 요청](/#part-1-03-first-request)을 봅니다.
4. 권한은 기본값 그대로 둡니다.
5. 대화창에 `@lab1`을 입력해 실행합니다. Codex가 1교시 전체 흐름과 지금 할 일을 안내하면, 강사 화면을 보며 그대로 따라갑니다.

## 실습 폴더는 이렇게 이어집니다

- **1교시와 2교시:** 같은 `tes-lab` 프로젝트를 계속 사용합니다. 1교시가 끝나면 휴식 시간에 강사 안내에 따라 2교시 연구소 데이터 폴더를 준비합니다.
- **3교시:** `tes-workmate` 업무 공간으로 이동합니다. 2교시 분석 결과를 바탕으로 내 업무 공간과 스킬을 구성합니다.
- 회사 기준상 승인되지 않은 사내 자료는 앱에 넣지 않습니다.
- 숫자나 결론이 나오면 원자료와 직접 대조합니다.
- 막히면 혼자 오래 붙잡지 말고 손을 듭니다. [막혔을 때](#lab-9-01-help)
