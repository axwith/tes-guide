# 연구소 과정 안내

> 당일 순서와 실습 폴더 받는 방법입니다. 각 교시는 **Codex 시작하기 → Codex 응용하기 → Codex 활용하기** 순서로 진행합니다.

---

## 오늘 순서

1회차 11월 24일(화), 2회차 11월 25일(수). 두 회차는 같은 내용입니다. 연구소 과정은 **3개 코스가 아니라, 한 과정 안에서 직무에 맞는 데이터 트랙을 선택**해 실습합니다.

| 교시 | 하는 일 | 끝나면 남는 것 |
|---|---|---|
| 1교시 **Codex 시작하기** | 강사 화면을 보며 사람이 일하는 다섯 단계, Codex가 일하는 방식, 폴더 열기·첫 요청·응답 읽기·권한 확인·다운로드 폴더 정리·플러그인 설치와 맛보기를 함께 진행합니다 | 정리 계획, 첫 확인 파일, 플러그인 사용 경험 |
| 2교시 **Codex 응용하기** | 직무에 맞는 데이터 트랙을 선택해 같은 다섯 단계로 분석하고, 대시보드와 한 장 보고를 만듭니다 | 분석 표, 대시보드, 한 장 보고 |
| 3교시 **Codex 활용하기** | 미리 읽어 둔 내 업무 파일로 내 업무 공간(`tes-workmate`)을 온보딩하고, 2교시 분석을 내 스킬로 만든 뒤 각자 내 업무 한 건 | 내 업무 공간, 결과 파일 1개 |

강사 화면을 보며 같은 순서로 따라 합니다. 결과 문장은 사람마다 달라도 흐름과 남는 파일이 같으면 됩니다. CVD 공정 데이터는 현재 실습 자료로 제공하며, 장비개발·제어 데이터는 **준비 중**입니다.

---

## 연구소 과정의 데이터 트랙 선택

연구소 과정 참석자는 2교시에서 본인 직무에 맞는 데이터 트랙 하나를 선택합니다. `/biz/` 혼합직무 과정은 운영·재무 등 업무 적용 과정으로 별도 유지됩니다.

| 대상 직무 | 선택할 트랙 | 안내 |
|---|---|---|
| 공정·CVD 관련 직무 | CVD 공정 데이터 | 현재 제공되는 기존 트랙입니다. 가상 증착 장비의 런 기록과 웨이퍼 두께 데이터를 사용합니다. |
| R/F·CAE·S/W·전장 | 장비개발·제어 데이터 | **준비 중**입니다. 실제 데이터 경로가 마련되기 전까지는 강사 안내에 따라 대체 실습 또는 공통 흐름을 진행합니다. |

`장비개발·제어 데이터` 트랙의 실습 폴더와 링크는 아직 공개하지 않습니다. 존재하지 않는 파일을 안내하지 않으며, 자료가 준비되면 이 안내를 업데이트합니다.

## 교육 전에 준비할 것

Codex 데스크톱 앱은 교육 전에 설치하고 회사 계정으로 로그인해 둡니다. 교육 당일에는 바로 Codex로 실습을 시작합니다. 설치하지 못했거나 로그인·업데이트에서 막힌 분은 손을 들어 알려 주세요. 1교시를 멈추고 기다리지 않고, 첫 휴식 시간에 보조강사가 @lab2 준비와 함께 도와드립니다.

교육 전에 미리 해 보지 못해도 괜찮습니다. 1교시에는 강사 화면을 보며 모두 함께 폴더를 열고 첫 요청부터 진행합니다.

## 1교시 실습 자료 받기

1교시에는 두 가지 방법 중 하나를 고릅니다.

### 내 다운로드 폴더로 해 보기

본인의 다운로드 폴더를 사용해도 됩니다. 단, 개인정보·회사 기밀·삭제하면 안 되는 원본은 사용하지 마세요. 파일을 바로 삭제하거나 옮기지 않고, 먼저 목록과 정리 계획을 확인합니다.

### 예제 파일로 해 보기

아직 미리 해 보지 못했거나 안전하게 따라 하고 싶은 분은 아래 가상 파일을 받습니다. 영수증·회의 자료·사진·설치 파일·압축 파일·중복 파일처럼 실제 다운로드 폴더에 있을 법한 자료가 들어 있습니다. 모든 파일은 교육용 가상 자료입니다.

**[예제 다운로드 폴더 받기 (tes-lab.zip)](/downloads/tes-lab.zip)**

1. 위 링크로 `tes-lab.zip`을 받습니다.
2. 압축을 풉니다.
   - Windows: 받은 파일을 오른쪽 클릭 → **모두 압축 풀기** → 바탕 화면을 고르고 **압축 풀기**
   - Mac: 받은 파일을 더블클릭하고, 생긴 `tes-lab` 폴더를 바탕 화면으로 옮깁니다.
3. `tes-lab` 폴더 안에 `1교시-실습`, `2교시-…` 폴더와 `README.md`가 보이면 됩니다.

**Codex 앱은 교육 전에 설치하고 로그인해 둡니다.** `tes-lab` 예제 ZIP은 1교시를 시작할 때 함께 내려받아도 됩니다. 강사 화면을 보며 압축을 풀고 폴더를 여는 것부터 진행합니다.

## Codex에서 폴더 열기

1. ChatGPT 데스크톱 앱을 열고 왼쪽 위가 **Codex**인지 확인합니다.
2. **새 채팅**을 먼저 누릅니다.
3. 새 채팅에서 `tes-lab` 폴더를 프로젝트로 엽니다. 방법이 기억나지 않으면 [작업 폴더 연결과 첫 요청](/#part-1-03-first-request)을 봅니다.
4. 권한은 기본값 그대로 둡니다.
5. 대화창에 `@lab1`을 입력해 실행합니다. Codex가 1교시 전체 흐름과 지금 할 일을 안내하면, 강사 화면을 보며 그대로 따라갑니다.
