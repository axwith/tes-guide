# 연구소 과정 안내

> 당일 순서와 실습 폴더 받는 방법입니다.

---

## 오늘 순서

1회차 11월 24일(화), 2회차 11월 25일(수). 두 회차는 같은 내용입니다. 연구소 과정은 **3개 코스가 아니라, 한 과정 안에서 직무에 맞는 데이터 트랙을 선택**해 실습합니다.

| 교시 | 하는 일 | 끝나면 남는 것 |
|---|---|---|
| 1교시 | 다운로드 폴더 정리로 다섯 단계(업무 파악 → 기획 → 만들기 → 검토 → 개선)를 한 바퀴 돌고, 플러그인을 설치해 써 봅니다 | 정리된 폴더, 플러그인 2개 |
| 2교시 | 직무에 맞는 데이터 트랙을 선택해 같은 다섯 단계로 분석하고, 대시보드와 한 장 보고를 만듭니다 | 분석 표, 대시보드, 한 장 보고 |
| 3교시 | 미리 읽어 둔 내 업무 파일로 내 업무 공간(`tes-workmate`)을 온보딩하고, 2교시 분석을 내 스킬로 만든 뒤 각자 내 업무 한 건 | 내 업무 공간, 결과 파일 1개 |

강사 화면을 보며 같은 순서로 따라 합니다. 결과 문장은 사람마다 달라도 흐름과 남는 파일이 같으면 됩니다. CVD 공정 데이터는 현재 실습 자료로 제공하며, 장비개발·제어 데이터는 **준비 중**입니다.

---

## 연구소 과정의 데이터 트랙 선택

연구소 과정 참석자는 2교시에서 본인 직무에 맞는 데이터 트랙 하나를 선택합니다. `/biz/` 혼합직무 과정은 운영·재무 등 업무 적용 과정으로 별도 유지됩니다.

| 대상 직무 | 선택할 트랙 | 안내 |
|---|---|---|
| 공정·CVD 관련 직무 | CVD 공정 데이터 | 현재 제공되는 기존 트랙입니다. 가상 증착 장비의 런 기록과 웨이퍼 두께 데이터를 사용합니다. |
| R/F·CAE·S/W·전장 | 장비개발·제어 데이터 | **준비 중**입니다. 실제 데이터 경로가 마련되기 전까지는 강사 안내에 따라 대체 실습 또는 공통 흐름을 진행합니다. |

`장비개발·제어 데이터` 트랙의 실습 폴더와 링크는 아직 공개하지 않습니다. 존재하지 않는 파일을 안내하지 않으며, 자료가 준비되면 이 안내를 업데이트합니다.

## 실습 폴더 받기

교육 시작 전에 받아 두면 바로 시작할 수 있습니다.

**[실습 폴더 받기 (tes-lab.zip)](/downloads/tes-lab.zip)**

1. 위 링크로 `tes-lab.zip`을 받습니다.
2. 압축을 풉니다.
   - Windows: 받은 파일을 오른쪽 클릭 → **모두 압축 풀기** → 바탕 화면을 고르고 **압축 풀기**
   - Mac: 받은 파일을 더블클릭하고, 생긴 `tes-lab` 폴더를 바탕 화면으로 옮깁니다
3. `tes-lab` 폴더 안에 `1교시-몸풀기`, `2교시-…` 폴더와 `README.md`가 보이면 됩니다. 폴더 안에 `tes-lab` 폴더가 한 번 더 있으면 안쪽 폴더를 씁니다.

압축 파일로 받아야 몸풀기 파일의 날짜가 그대로 남습니다. 다른 방법으로 옮기지 말고 압축을 풀어 씁니다.

1. ChatGPT 데스크톱 앱을 열고 왼쪽 위가 **Codex**인지 확인합니다.
